# 定格扩展翻译与 Ollama（设计备忘）

> 宪法依据：`.specify/memory/constitution.md` **v2.0.0**（Purpose + 原则 II）。  
> 正式玩家可见规格尚未写；下一步用 Spec Kit 开 **007**，本文件在此之前作决策记录。  
> **本阶段不做 OCR。**

## 产品意图

在 F3+K 定格下，辅助非母语游玩与高频接触学习：能取到游戏语言包对照则优先用对照；否则取词或机翻兜底。物品等专有名词仍以语言包 / 现有双语提示为主。

## 解析优先级

1. **取词模式（默认）**  
   - 光标下英文词 → 内置词典（ECDICT 按频次截断）→ 未命中且 Ollama 开启则 `qwen2.5:1.5b`。  
   - 暂时只做 **英→中**。  
   - 即使该处有官方对照整段，取词模式也 **只显示该词释义**，不自动弹出整段对照。

2. **取整句 / 对照段模式**（定格热键或浮窗按钮切换）  
   - **有 i18n 翻译单元**：显示对照语言下该组件/键的 **全文**（可含多句，不按标点再切）。  
   - **无对照**：按中英句末标点切出光标所在 **单句**（一次一句，不整段多句送模）→ `qwen2.5:3b`。  
   - 玩家聊天、改名、手写书页等 UGC：无语言包对照时走 Ollama（若开启）。

3. **取不到主语言可见字符串**（不做 OCR）→ 提示「无法翻译」一类文案。

## 术语

| 术语 | 含义 |
| --- | --- |
| 翻译单元 / 对照段 | 一个 `TranslatableContents`（一个语言键）展开后的全文，可含多句 |
| 机翻单句 | 无对照时按。！？.… ! ? 等切出的一句，供 Ollama |
| 取词 | 光标下英文词的词典或小模型释义 |

有官方对照时用翻译单元，比先切单句再查包更简单、也更正确。标点切句只服务机翻延迟控制。

## 词典

- 数据源：**ECDICT（MIT）按频次截断**，不使用不可再分发的商业 COCA 词表。  
- 随模组分发；包体以截断后的词+精简释义为准。  
- 不单独部署 HTTP 词典服务；未命中词与整句机翻统一走本机 Ollama。

## Ollama

- **可选**，客户端配置开关，**默认开启**。  
- 非硬依赖：模组无 Ollama 也能加载；扩展翻译在运行时失败。  
- 未安装或调用失败：**每次悬停都显示错误**，直到玩家在模组设置里关闭扩展翻译。  
- 仅本机 HTTP（默认 `127.0.0.1:11434`）。  
- 固定模型（便于提示词与性能调优，不开放任意模型）：  
  - 单词：`qwen2.5:1.5b`  
  - 整句：`qwen2.5:3b`  
- 需要加载态、超时、失败提示；同句结果宜缓存。

## 交互

- 定格内热键切换取词 / 取整句（对照段）模式。  
- UI 浮窗提供同步切换按钮。  
- 默认模式：取词。

## 许可

- 早期个人/朋友试用；长期可接受模组与依赖走向 **GPL / AGPL**。  
- 词典与库按上游协议附带 NOTICE/LICENSE。

## 明确不做（本阶段）

- OCR / 截图像素取词。  
- 独立 HTTP 词典服务。  
- 中文主语言下的中→英取词。  
- 合并多个相邻翻译键为视觉「一大段」（悬停只对应当前键）。
