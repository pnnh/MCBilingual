# 定格扩展翻译与 Ollama（设计备忘）

> 宪法依据：`.specify/memory/constitution.md` **v2.1.0**（Purpose + 原则 II）。  
> 正式规格：`specs/007-freeze-extended-translate/`（文本路径）；视觉兜底见 **`specs/008-*`**。  
> 冲突时以对应 feature 规格为准。

## 产品意图

在 F3+K 定格下，辅助非母语游玩与高频接触学习：能取到游戏语言包对照则优先用对照；否则取词或机翻兜底；绘制管线无字符串时可用本机 **视觉模型** 做句/段级兜底。物品等专有名词仍以语言包 / 现有双语提示为主。

## 解析优先级

1. **取词模式（默认）**  
   - 光标下英文词 → 内置词典（ECDICT 按频次截断）→ 未命中且 Ollama 开启则 `qwen2.5:1.5b`。  
   - **英→中**（文本机翻与视觉兜底均暂定此方向，不随主语言切换译出语）。  
   - 即使该处有官方对照整段，取词模式也 **只显示该词释义**，不自动弹出整段对照。  
   - **视觉兜底不做取词**（实现难度与误识率；仅句/段）。

2. **取整句 / 对照段模式**（定格热键或浮窗按钮切换）  
   - **有 i18n 翻译单元**：显示对照语言下该组件/键的 **全文**（可含多句，不按标点再切）。  
   - **无对照但有可见字符串**：按中英句末标点切出光标所在 **单句** → `qwen2.5:3b`。  
   - 玩家聊天、改名、手写书页等 UGC：无语言包对照时走文本 Ollama（若开启）。

3. **绘制管线取不到主语言可见字符串**  
   - 仅 **对照段** 模式；扩展翻译开启 → 裁剪光标附近定格图 ROI → 本机 **`qwen2.5vl:3b`**（固定）识别并译为 **简体中文** 一句或短段落。  
   - **不**在模组 jar 内嵌独立 OCR 引擎。

## 状态提示（心理预期）

悬停时 MUST 区分管道，避免用户用文本机翻的耐心等视觉模型：

| 状态 | 示例文案（中/英键） |
| --- | --- |
| 文本路径进行中 | 文本识别中… / Translating text… |
| 视觉路径进行中 | 图片识别中… / Recognizing image… |
| 无结果 / 不可用 | 无法翻译 / Cannot translate |
| 超时 / 失败 | 既有超时、失败文案；可注明是文本还是图片管道 |

词典命中与语言包对照仍可立即显示，无需「识别中」。

## 术语

| 术语 | 含义 |
| --- | --- |
| 翻译单元 / 对照段 | 一个 `TranslatableContents`（一个语言键）展开后的全文，可含多句 |
| 机翻单句 | 无对照时按标点切出的一句，供文本 Ollama |
| 取词 | 光标下英文词的词典或小文本模型释义 |
| 视觉兜底 | 无绘制字符串时，ROI 截图 + Ollama VL 句/段翻译 |

## 词典

- 数据源：**ECDICT（MIT）按频次截断**。  
- 不单独部署 HTTP 词典服务。

## Ollama

- **可选**，客户端配置开关，**默认开启**。  
- 非硬依赖。  
- 未安装或调用失败：每次悬停显示错误，直到配置关闭。  
- 仅本机 HTTP。  
- 固定模型：  
  - 单词文本：`qwen2.5:1.5b`  
  - 整句文本：`qwen2.5:3b`  
  - 视觉兜底：`qwen2.5vl:3b`（**不是** `qwen2.5` 文本模；后者无视觉）  
- 需要加载态、超时、失败提示与缓存。

## 交互

- 定格内热键切换取词 / 对照段：未绑定默认为 **L**。  
- 右上角浮窗按钮同步切换。  
- 默认模式：取词。  
- 配置：`config/mcbilingual-client.toml` → `extended_translation.*`（含 `requestTimeoutMs`、`visionTimeoutMs`、`ollamaBaseUrl`）。

## 许可与分发

- 模组 jar **不**捆绑原生 OCR；视觉能力由玩家 `ollama pull`。  
- 利于 CurseForge / Modrinth 分发与跨 OS。

## 明确不做（除非新规格）

- jar 内嵌 Tessseract 等 OCR 引擎。  
- 视觉路径下的单词级取词。  
- 独立 HTTP 词典服务。  
- 中→英取词（仍仅英→中）。
