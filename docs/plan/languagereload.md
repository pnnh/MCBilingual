# Language Reload 核心功能

参考来源：`thirdpart/LanguageReload`，分支 `1.21.1`，模组 1.7.6。

- Minecraft 1.21.1
- Fabric Loader 0.16.7，Yarn `1.21.1+build.3`，Fabric API `0.106.0+1.21.1`
- 仅客户端
- 许可证 MIT
- 没有 NeoForge 构建。这条分支不能移植成加载器代码，只能重写行为。

玩家看到的仍是一种合并后的语言，不是两行双语。

## 快速重载

`reloadLanguages()` 只重载语言管理器，不走完整资源包重载。重载后刷新：

- 窗口标题
- 聊天栏缩放缓存
- 当前打开的书页缓存
- 当前打开的进度界面
- 已加载区块里告示牌正反面的排版缓存
- 文本展示实体的行缓存

## 快捷键

在 Fabric 的 F3 处理里：

- F3+J：重载当前语言。
- Shift+F3+J：切回上一次的语言和后备列表。

README 写的是 “cycling”。1.21.1 源码实际是与上一组选择对调，不是在更长的语言列表里循环。

## 语言界面

- 语言选择屏幕分成两列，并带搜索。
- 玩家可以把语言加入已选、移出、上下调整顺序。
- 已选列表的第一项是当前语言，后面的项是后备。上面的翻译覆盖下面的。
- 一项都不选表示没有语言。
- `en_us` 默认不能移除。配置打开 `removableDefaultLanguage` 后才可以。
- 选项里没有 `lang` 时，按操作系统语言自动选择。

## 多语言搜索

- 创造模式物品栏和配方书的搜索包含后备语言里的提示文本。
- 可以在 Mod Menu 或配置文件里关掉（`multilingualItemSearch`，默认开）。
- 语言存储按语言分开，并用线程上的目标语言决定当前取词。
- 不接入 JEI、EMI、Jade，也不做拼音。

## 其他行为

- 配置记在 `config/languagereload.json`：当前语言、后备列表、上一组语言和后备、两项开关。
- 切换语言时同步游戏选项里的语言并写盘。
- 海盗话语（配方书相关）会把语言设成 `en_pt`。

## 它没有的能力

- 不在提示框加第二语言行。
- 不支持 NeoForge。
- 不集成 JEI 或 Jade。
- 不做拼音。
- 不同时在屏幕上显示两种语言。后备语言只用于缺词填充和创造/配方书搜索。

## 对本项目的含义

现阶段只借用一个行为：启动时把两种语言的文案都放进内存，用一个快捷键更换当前主语言，并只刷新依赖语言的界面缓存，不走完整资源重载。

不借用：多语言后备栈、双列语言界面、空语言、可移除的默认英文、海盗话语、创造栏和配方书搜索。MCBilingual 的搜索范围是 JEI，语言对只有中文和英文。
