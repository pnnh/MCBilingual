# Quickstart: 008 视觉兜底与状态提示

## 前置

1. 007 行为可用（定格 F3+K、取词/对照段、扩展翻译配置）。
2. 安装 [Ollama](https://ollama.com/)，本机默认端口。
3. 拉取模型：
   - 文本：`ollama pull qwen2.5:1.5b` 与 `ollama pull qwen2.5:3b`（007）
   - 视觉：`ollama pull qwen2.5vl:3b`（本 feature）
4. `./gradlew runClient`
5. 配置项：`extended_translation.visionTimeoutMs`（默认 60000）；关 `enabled` 后无视觉请求。

## 用例 A — 图片识别中 → 译文

1. 打开**绘制管线无字符串**的 UI（如已知的模组自绘书页）。
2. F3+K 定格，切换到**对照段**模式。
3. 悬停无串区域：应先见 **「图片识别中…」**（或英键），稍后见句/段译文。
4. 关 `extendedTranslation`：同处不再请求，不出现图片识别中。

## 用例 B — 文本识别中（对照）

1. 定格后悬停**有可见英文串、词典未收录、扩展开**的词（取词模式）。
2. 等待中应见 **「文本识别中…」**，**不得**见「图片识别中…」。
3. 有语言包对照的对照段模式：立即对照，无识别中。

## 用例 C — 错误区分

1. 停止 Ollama。
2. 触发文本 MT：错误文案属文本管道。
3. 在 UNIT 无串处触发视觉：错误文案属图片管道（或标明图片）。
4. 取词模式空白处：无法翻译，且无视觉 HTTP。

## 用例 D — 模式浮窗

悬停右上角模式按钮时，不应用 recognizing / 无法翻译抢焦点。
