# Quickstart: 应用能源终端与殖民地物品的语言

实现之后在客户端里核对。创造模式或管理员命令只用于取得物品和放置方块，不代替下面的观看步骤。

## 准备

1. `./gradlew runClient`。首次启动需要网络，任务会把简体中文资源包下载到 `run/resourcepacks` 并在已有 `options.txt` 里启用。应用能源和殖民地的物品中文来自它们自己的 jar。不要把资源包提交进仓库。
2. 进入一个创造模式世界。若资源包没能下载，停在这一步，先补上开发会话里的中文资源。
3. 打开高级提示（F3+H），之后命令里的物品标识以游戏显示的为准。

## 应用能源终端

1. 从创造物品栏取出能源、线缆、一个能存放物品的存储方块和物品终端，放成一个可打开的小型网络。不需要玩完应用能源的进度。
2. 向网络存入一件中英名称都有的物品。苹果可以用来对照；再存一件应用能源或殖民地自己的物品。
3. 主语言为英文时，用该物品的中文名搜索。主语言为中文时，用英文名搜索。两种主语言下都再用全拼和首字母各搜一次。四次都应看到该物品。
4. 列表上的名字是当前主语言。把鼠标放在终端里的物品上：有另一种语言时标题下有一行，没有拼音。
5. 按住 F3 再按 J。一秒内列表名称改为新语言；若没有改，关闭终端再打开后必须是新语言。不出现资源重载画面。用切换前的另一种语言名称再搜一次，物品仍在。

## 殖民地

1. 从创造物品栏取出建造工具，看提示框。中文存在时，两种主语言下都有另一语言的第二行。看着一个殖民地方块，注视提示使用同一规则。
2. 若工作台必须先有殖民地才能打开，只做该模组要求的最短放置（补给营地或等价的创造放置），直到能打开一个建筑界面。不完成整个殖民地任务。
3. 打开该界面，记下标题和一件物品名。按语言快捷键。一秒内改为新语言；若界面保持旧句子，关闭再打开后必须是新语言。窗口里的普通按钮不加第二行。
4. 聊天栏打开时按 F3+J，语言不切换。

## 冲突

1. 再放上 Polyglot Tooltip 或 Language Reload，启动客户端。日志里有本模组已停用的说明，游戏能进世界。
2. 进入世界后聊天有一条说明。物品提示没有本模组的第二行。按语言快捷键后，语言选项不变。
3. 拿掉这两个模组、只留中文资源包时，本模组恢复提示、搜索和快捷键。

## 缺件

1. 去掉中文来源后再进世界。上述物品显示英文名，第二行不出现裸翻译键，游戏不崩溃。
2. 去掉应用能源和殖民地后再进世界。背包提示、JEI 搜索和语言快捷键仍可用。

单测只覆盖「一段查询被某条搜索词包含」这一规则，不能代替上面的终端和工作台。
