# Contract: 殖民地物品与工作台名称

殖民地和中文来源都在开发会话里，且语言表就绪时：

1. 殖民地特有物品的提示第一行是当前主语言。另一种语言有文案时，第二行是那种语言。没有文案时不显示第二行，也不显示裸翻译键。
2. 注视该模组方块或对应实体时，名称的第二行与物品提示相同。
3. 工作台窗口的标题和物品名使用当前主语言。窗口里的普通标签不加第二行。
4. 按下语言快捷键后，会跟着当前语言重绘的标题和物品名在一秒内更新。记住旧句子的窗口，关闭再打开后是新语言。
5. 切换不打开资源重载画面，也不回到标题画面。第一次按键前不改变当前语言。
6. 拼音不出现在这些名称或提示上。

中文来源缺失时，这些物品显示英文名，第二行省略，客户端仍能进入世界。殖民地未安装时，本契约不生效，已有的提示和快捷键保持可用。
