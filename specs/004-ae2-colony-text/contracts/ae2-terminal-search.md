# Contract: 应用能源物品终端搜索

应用能源已安装、语言表就绪，且玩家打开的是物品终端（或使用同一物品搜索框的合成终端）时：

1. 一件物品的简体中文名、英文名、无声调连续全拼或首字母被包含在查询的一段普通词里时，该物品命中。大小写不改变结果。
2. 当前主语言是中文还是英文，不改变这四种词。
3. 当前显示名原来就能命中的查询，仍然命中。
4. 切换主语言后不需要重启，四种词仍然可用，且这次切换不重建搜索词。
5. 终端列表和提示上的名称是当前主语言。另一种语言有文案时，提示标题下有第二行。拼音不出现在列表、提示或搜索框。
6. 物品没有中文名时，拼音和中文名不是本模组的命中条件。英文显示名仍按终端原有方式命中。
7. 流体、样板访问和无线终端不使用本契约。`@`、`#`、`$`、`*` 开头的查询保持终端原有含义。
8. 打字和切换都不打开资源重载画面。空结果不导致崩溃。

应用能源未安装时，本契约不生效，客户端仍能进入世界。
