# Feature Specification: 应用能源终端与殖民地物品的语言

**Feature Branch**: `004-ae2-colony-text`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "开发阶段加入应用能源 19.2.18 和殖民地 1.1.1405，验证双语显示和语言切换。重点是应用能源搜索终端，以及殖民地特有物品和工作台。中文来自外部汉化，不随本模组发布。玩家用创造模式或管理员命令取得测试物品。"

## Clarifications

### Session 2026-10-22

- Q: 使用 AGPL 协议的源码或依赖时，是否把本模组改成 AGPL？ → A: 不改。只把 AGPL 程序当作独立模组一起运行，不复制源码，也不打进发布包。若将来把源码或 jar 打进发布包，再把发布物改为 AGPL。
- Q: 应用能源、殖民地和它们的前置要兼容哪条版本线？ → A: Minecraft 1.21.1，以及 NeoForge 21.1.251 和同一条线上的更新版本。
- Q: 与同类多语言模组同时安装时如何处理？ → A: 本模组停止自己的提示、搜索和语言切换，游戏仍可进入世界。客户端日志在启动时记录，聊天区在进入世界时记录一次。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 遇到同类语言模组时停用自己 (Priority: P1)

玩家同时安装了本模组和另一个会改双语提示、混合搜索或客户端语言切换的模组。游戏能够进入世界。本模组不再改提示、搜索或语言，也不改存档和语言选项。启动日志和进入世界后的聊天各有一条说明。

**Why this priority**: 两套语言注入叠在一起会崩溃或把界面写乱。先退让，其它功能才有意义。

**Independent Test**: 开发客户端同时放上 Polyglot Tooltip 或 Language Reload 之一。进入世界，看日志和聊天，再看物品提示是否没有本模组的第二行，语言选项是否保持原样。

**Acceptance Scenarios**:

1. **Given** Polyglot Tooltip 或 Language Reload 已安装，**When** 客户端启动，**Then** 日志写明本模组已停用以及检测到的模组，游戏不因这个冲突崩溃。
2. **Given** 玩家进入世界，**When** 聊天出现，**Then** 有一条说明，且同一次运行里只出现一次。
3. **Given** 本模组已停用，**When** 玩家查看物品提示、搜索物品或按下语言快捷键，**Then** 本模组不添加第二行、不扩展搜索、不切换语言，也不写入语言选项。
4. **Given** 只安装了提供中文文案的更新模组或资源包，**When** 玩家进入世界，**Then** 本模组照常工作，不把它们当成冲突。

---

### User Story 2 - 在应用能源终端里用中文、英文或拼音找物品 (Priority: P1)

玩家打开应用能源的物品搜索终端，里面已经存着物品。无论当前主语言是中文还是英文，玩家都可以用物品的中文名、英文名、无声调全拼或首字母找到它。终端里看到的名称仍是当前主语言，不出现拼音。

**Why this priority**: 终端有自己的搜索框。已有的物品清单搜索不会作用到这个框。这是玩家点名的第一处验证。

**Independent Test**: 开发用的客户端装有应用能源、中文文案和本模组。用创造模式搭一个能打开的终端，存入一个两边语言都有名称的物品，分别用另一种语言的名称、全拼和首字母搜索。

**Acceptance Scenarios**:

1. **Given** 终端里有一个中文名和英文名都存在的物品，且当前主语言是英文，**When** 玩家输入它的中文名，**Then** 该物品出现在终端结果中。
2. **Given** 同一终端、同一物品，且当前主语言是中文，**When** 玩家输入它的英文名，**Then** 该物品出现在结果中。
3. **Given** 物品中文名可以转成无声调全拼和首字母，**When** 玩家输入全拼或首字母，**Then** 该物品出现在结果中。
4. **Given** 玩家正在终端里查看结果，**When** 看物品名称，**Then** 名称是当前主语言，拼音不出现在名称、提示框或搜索框里。
5. **Given** 玩家只用当前语言的名称搜索，**When** 查看结果，**Then** 终端原有的按当前名称查找仍然可用。

---

### User Story 3 - 殖民地物品和工作台跟随两种语言 (Priority: P1)

玩家用创造模式或管理员命令拿到殖民地模组自己的物品，并把一个工作台界面打开。物品提示显示当前主语言，另一种语言在有文案时作为第二行。工作台界面上的标题和物品名使用当前主语言。按下已有的语言快捷键后，这些文字改成另一种语言，且不出现资源重载画面。

**Why this priority**: 原版没有这些物品的中文。玩家要确认外部汉化进来之后，显示和切换对殖民地自己的物品、方块和工作台仍然成立。

**Independent Test**: 开发用的客户端装有殖民地、它启动所需的配套、中文文案和本模组。创造模式拿起一件殖民地特有物品，看提示框；打开一个工作台界面，按语言快捷键，看标题和物品名。

**Acceptance Scenarios**:

1. **Given** 一件殖民地特有物品在中文和英文里都有名称，**When** 玩家把鼠标放在它上面，**Then** 第一行是当前主语言，第二行是另一种语言。
2. **Given** 玩家看着殖民地的方块或对应实体，**When** 注视提示出现名称，**Then** 第二行规则与物品提示相同。
3. **Given** 一个殖民地工作台界面已经打开，**When** 玩家按下语言快捷键，**Then** 一秒内标题和界面上的物品名变为新的主语言；若该界面记住了旧句子，关闭再打开后必须是新语言。
4. **Given** 切换发生时，**When** 玩家看屏幕，**Then** 不出现资源重载画面，也不回到标题画面。
5. **Given** 玩家还没有按过快捷键，**When** 打开工作台，**Then** 文字保持游戏当前语言，不主动改掉。

---

### User Story 4 - 终端里的名称和提示也跟着切换 (Priority: P2)

玩家站在已经打开的应用能源终端前切换语言。列表里的物品名改成新的主语言。把鼠标放在终端里的物品上时，提示的第一行是新的主语言，另一种语言在有文案时仍是第二行。搜索框里刚才用中文、英文或拼音找到的物品，切换后不用重新输入也能继续按这些词找到。

**Why this priority**: 搜索和显示是两件事。终端能搜到之后，还要确认切换不会把名称或第二行弄丢。

**Independent Test**: 终端里存有一个两边都有名称的物品。切换语言前后各看一次名称和提示，并用切换前的另一个语言词再搜一次。

**Acceptance Scenarios**:

1. **Given** 终端列表正在显示物品，**When** 玩家按下语言快捷键，**Then** 一秒内列表名称变为新的主语言；若列表记住了旧名称，关闭再打开后必须是新语言。
2. **Given** 该物品两种语言的文案都存在，**When** 玩家在终端里查看它的提示，**Then** 第一行是当前主语言，第二行是另一种语言。
3. **Given** 切换已经完成，**When** 玩家用切换前有效的中文名、英文名、全拼或首字母再搜索，**Then** 同一物品仍然出现，且这次切换没有要求玩家等待一份新的搜索词表被重新制作。

---

### Edge Cases

- 中文文案来源没有装上，或某个物品没有中文：玩家仍能进入世界。物品显示模组自带的英文名。第二行不出现，也不出现裸翻译键。拼音和中文名不作为本模组的搜索条件。英文名仍可按该界面原有方式找到。
- 应用能源或殖民地没有装上：玩家仍能进入世界。已有的物品提示、注视提示、物品清单搜索和语言快捷键保持原样。本功能里依赖它们的场景不执行。
- 终端是空的，或搜索没有命中：结果为空，客户端不崩溃。
- 搜索框打开时玩家按下语言快捷键：语言可以切换。聊天输入框打开时仍不切换。
- 工作台因为还没有殖民地而拒绝打开：测试改用创造模式完成该模组要求的最短放置步骤，不要求玩完整个殖民地进程。打不开的界面不算本功能失败，只要同一会话里能打开一个工作台。
- 终端还没有连上可用网络：先用创造模式放好终端能够搜索的最小装置，再验证搜索。
- 两份中文来源同时存在且词条相同：玩家只看到一行中文，不看到重复的第二行。
- 流体、样板访问和无线终端不在本功能的搜索验收里。合成终端如果使用与物品终端相同的物品搜索框，则同一套词对它有效。
- 同类语言模组已安装时，本功能的搜索、第二行和切换都不执行。玩家仍能进入世界，存档和语言选项保持原样。
- 提供译文的模组或资源包不算同类语言模组。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 开发用的客户端必须能够同时启动本模组、应用能源 19.2.18、殖民地 1.1.1405，以及这两个模组各自声明的、缺少就会无法进入世界的配套。这些模组都必须支持 Minecraft 1.21.1，以及 NeoForge 21.1.251 和同一条线上的更新版本。
- **FR-013**: 发布的模组必须保持现有许可证。不复制 AGPL 源码，jar 不进入发布包。I18nUpdateMod 3.7.0 在 NeoForge 21.1.251 上会被跳过，开发会话改用各模组自带的语言文件和未提交的简体中文资源包。
- **FR-014**: 同时安装 Polyglot Tooltip 或 Language Reload 时，本模组必须停用自己的提示、搜索和语言切换。游戏必须仍能进入世界。启动时写客户端日志，进入世界时在聊天区记录一次。不得因此修改存档或语言选项。
- **FR-015**: 只提供中文文案的模组或资源包不得触发 FR-014。
- **FR-002**: 开发用的客户端必须带有这些模组物品的简体中文来源。中文来自外部汉化，不放进本模组，也不随本模组发布。
- **FR-003**: 玩家必须能用创造模式或管理员命令取得测试用的物品和方块，而不必先完成这两个模组的任务线。
- **FR-004**: 应用能源物品终端的搜索必须能用物品的简体中文名、英文名、无声调连续全拼和首字母命中该物品。当前主语言不改变这四种词。
- **FR-005**: 终端搜索命中后，显示出来的名称必须仍是当前主语言。拼音不得出现在终端名称、提示框、搜索框、殖民地物品提示或注视提示上。
- **FR-006**: 终端里查看物品提示时，若另一种语言有文案，必须在标题下显示第二行；没有文案时必须省略第二行。
- **FR-007**: 殖民地特有物品的提示，以及注视这些方块或对应实体时的名称，必须使用与现有物品相同的第二行规则。
- **FR-008**: 殖民地工作台界面的标题和物品名必须使用当前主语言。语言快捷键之后，已打开的界面在一秒内更新；若它保留旧句子，关闭再打开后必须是新语言。
- **FR-009**: 语言切换不得打开资源重载画面，不得回到标题画面，也不得为了这次切换重新制作搜索词。
- **FR-010**: 某个物品没有中文时，客户端不得崩溃，不得把裸翻译键当作第二行，也不得用拼音冒充中文名。
- **FR-011**: 应用能源或殖民地缺失时，客户端必须仍能进入世界，且已有的提示、物品清单搜索和语言快捷键保持可用。
- **FR-012**: 只在简体中文和英文之间显示和切换。第一次按键前不改变玩家当前语言。

### Key Entities

- **物品的两种名称**: 一件物品在简体中文和英文下各自的可见名称。缺少的一种不补成翻译键。
- **搜索词**: 由两种名称得出的中文、英文、无声调全拼和首字母。只用于查找，不用于显示。
- **终端查询**: 玩家在应用能源物品搜索框中输入的文字，以及终端据此列出的物品。
- **工作台界面**: 殖民地建筑打开后的窗口，其中的标题和物品名跟随当前主语言。
- **外部中文来源**: 开发会话里提供第三方物品中文的文案。不属于本模组的内容，也不算冲突模组。
- **冲突的语言模组**: 会自行改双语提示、混合搜索或客户端语言切换的模组。本阶段就是 Polyglot Tooltip 和 Language Reload。检测到其中任意一个时，本模组的上述行为全部停止。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在装有应用能源和中文文案的会话里，玩家对终端中一件两边都有名称的物品，用另一种语言的名称、全拼和首字母各搜索一次，三次都在当前结果里看到该物品。
- **SC-002**: 上述物品在背包提示和终端提示里都显示两种语言；玩家在这些文字里看不到拼音。
- **SC-003**: 按下语言快捷键后的一秒内，终端列表名称和已打开的殖民地工作台标题、物品名变为新语言；做不到即时更新的界面，关闭再打开后正确。整个过程没有资源重载画面。
- **SC-004**: 一件殖民地特有物品在中文文案存在时，提示框在两种主语言下都带有另一种语言的第二行。
- **SC-005**: 拿掉中文来源后，玩家仍能进入世界；上述物品显示英文名，第二行不出现裸翻译键。
- **SC-006**: 拿掉应用能源和殖民地后，玩家仍能进入世界，原有提示、物品清单搜索和语言快捷键仍可用。
- **SC-007**: 同时安装 Polyglot Tooltip 或 Language Reload 时，玩家仍能进入世界。启动日志和进入世界后的一条聊天都写明本模组已停用。物品提示没有本模组的第二行，语言选项与进入前一致。
- **SC-008**: 开发会话里的应用能源、殖民地及其前置都能在 Minecraft 1.21.1、NeoForge 21.1.251 上进入世界。发布包的许可证与加入这些开发模组之前相同。

## Assumptions

- 「搜索控制台」指应用能源的物品终端搜索框。合成终端若使用同一个物品搜索框，适用同一规则。样板访问、流体和无线终端不单独立项。
- 「殖民地特有物品」指该模组自己的物品和方块，例如建造工具和建筑方块。「工作台」指这些建筑打开的操作界面，不是给每个按钮都加第二行。
- 工作台窗口里，第二行只出现在物品提示上。窗口其余标签只跟随当前主语言，不扩成整页双语。
- 应用能源和殖民地的简体中文来自它们自己的 jar。开发会话另外下载简体中文资源包到 `run/resourcepacks`，不把文案抄进本仓库。I18nUpdateMod 3.7.0 含 `fabric.mod.json`，NeoForge 21.1.251 会跳过它，所以不放进运行类路径。
- 只放下玩家点名的两个模组文件还不能进入世界。应用能源若声明还需要指南配套，开发会话一并装上。殖民地还需要它声明的结构、界面和相关配套。版本以 1.1.1405 这一个文件里写明的范围为准。
- 测试物品由玩家在客户端运行后用创造模式或管理员命令取得。殖民地工作台若必须先有殖民地才能打开，玩家只做打开一个工作台所需的最短放置，不玩完任务线。
- 已有的两种语言范围、提示第二行、拼音只用于搜索、以及快捷键不重载资源，都继续有效。本功能只把这些规则延伸到上述两个模组的指定界面。
- 发布出去的模组不要求玩家安装应用能源、殖民地或任何汉化包。
- 冲突名单只有 Polyglot Tooltip（标识 `polyglottooltip`）和 Language Reload（标识 `languagereload`）。自动汉化更新和简体中文资源包不在这份名单里。
- 开发用的 NeoForge 仍是 21.1.251。配套模组的元数据必须接受这个版本以及同一条线上的更新版本，本模组不为此改自己的构建版本。
- 本模组许可证保持 All Rights Reserved。接受「若把 AGPL 代码打进发布包就改为 AGPL」，当前不打进，所以不改。
