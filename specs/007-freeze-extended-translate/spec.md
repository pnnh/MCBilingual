# Feature Specification: 定格扩展取词与对照段 / 机翻

**Feature Branch**: `007-freeze-extended-translate`

**Created**: 2026-10-24

**Status**: Draft

**Input**: User description: "在已有 F3+K 定格上扩展：默认取词（英→中，ECDICT 频次截断词典，未命中可走本机 Ollama qwen2.5:1.5b）；切换到对照段模式后，有语言包则显示整段对照，无对照则按标点切单句并用 Ollama qwen2.5:3b；含玩家聊天/改名/书页等 UGC；不做 OCR；Ollama 可选默认开，失败每次悬停报错直至配置关闭；客户端配置；覆盖 006 中禁止机翻与禁止 UGC 提示的条款。"

## Clarifications

### Session 2026-10-24 (from product decisions)

- Q: 有语言包多句任务段落时，机翻路径是否仍先切单句？ → A: 有对照时显示**整个翻译单元**（可多句），不切分。标点切单句只用于无对照的机翻。
- Q: 词典用 COCA？ → A: 否。用可再分发的 **ECDICT（MIT）按频次截断**。
- Q: 中文主语言取词？ → A: 本特征只做 **英→中** 取词。
- Q: 有官方对照时取词模式显示什么？ → A: 只显示**该词释义**，不自动弹出整段对照。默认模式为取词。
- Q: Ollama 未安装？ → A: 扩展翻译开启时**每次悬停显示错误**，直到玩家在模组配置中关闭。
- Q: OCR？ → A: 本特征不做。取不到可见主语言字符串则提示无法翻译。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 定格默认取词看英文释义 (Priority: P1)

玩家在英文界面定格后，默认处于取词模式。鼠标移到一个英文单词上时，光标旁出现该词的中文释义（来自模组附带的常见词表）。词表没有时，若已开启扩展翻译且本机翻译服务可用，则出现加载后再显示机翻释义；服务不可用则每次悬停看到明确错误提示。

**Why this priority**: 取词是默认学习路径，覆盖最高频需求。

**Independent Test**: 定格后不切换模式，悬停常见英文词（如 `Apple` 语境外的普通词，或界面上的 `Settings`）能看到中文释义；关掉扩展翻译后，词典未收录词不再请求机翻。

**Acceptance Scenarios**:

1. **Given** 定格已开启且为取词模式，**When** 鼠标停在词典收录的英文词上，**Then** 光标旁显示该词中文释义（无需等待机翻）。
2. **Given** 取词模式且该词不在词典、扩展翻译开启且服务可用，**When** 悬停该词，**Then** 先出现加载提示，成功后显示释义。
3. **Given** 取词模式且扩展翻译开启但服务不可用，**When** 悬停词典未收录词，**Then** 每次悬停都显示失败/不可用提示，直到玩家在配置中关闭扩展翻译。
4. **Given** 该处文字另有语言包整段对照，**When** 仍处于取词模式，**Then** 只显示词义，不自动显示整段对照。

---

### User Story 2 - 切换到对照段 / 单句机翻 (Priority: P1)

玩家用定格内快捷键或浮窗按钮切到「对照段」模式。有游戏或模组语言包对照时，悬停该翻译单元任意可见部分，显示对照语言下的**整段**（可含多句）。无对照时，只取光标所在、按句末标点切出的**一句**，经本机机翻后显示；玩家聊天、改名、手写书页等同理。

**Why this priority**: 与取词并列的核心学习路径；任务书等多句文案依赖整段对照。

**Independent Test**: 悬停有中英语言包的任务说明，对照段模式看到整段中文；悬停玩家聊天一句，在服务可用时得到单句机翻。

**Acceptance Scenarios**:

1. **Given** 对照段模式且存在语言包翻译单元，**When** 悬停该单元任一可见行，**Then** 显示对照语言全文，且不因段内有多个句号而只显示一句。
2. **Given** 对照段模式且无语言包对照、扩展翻译开启且服务可用，**When** 悬停一段多句文字中的某一句，**Then** 只翻译并显示该句，不整段多句一次送翻。
3. **Given** 对照段模式，**When** 悬停玩家聊天、改名物品名或手写书页中可取得的可见字符串，**Then** 走机翻（或加载/失败提示），而不是静默无提示。
4. **Given** 定格中，**When** 玩家按模式切换快捷键或点浮窗按钮，**Then** 取词与对照段模式互相切换，浮窗状态与当前模式一致。

---

### User Story 3 - 配置开关与无法取词 (Priority: P2)

玩家可在客户端模组配置中开启或关闭扩展翻译（默认开启）。关闭后不再请求本机机翻；词典取词与语言包对照段仍可用。画面上取不到任何主语言可见字符串时，提示无法翻译，不做光学识别。

**Why this priority**: 保证无本机服务时玩家能关掉噪音；明确无 OCR 边界。

**Independent Test**: 配置关闭后悬停未收录词不再出现机翻错误；对纯贴图无字符串区域悬停出现无法翻译。

**Acceptance Scenarios**:

1. **Given** 配置中扩展翻译为关，**When** 悬停词典未收录词或无对照 UGC，**Then** 不调用本机机翻；取词模式可仍显示词典命中，对照段模式仍可显示语言包对照。
2. **Given** 配置中扩展翻译为开（默认），**When** 模组首次加载，**Then** 不因本机服务未安装而无法进入世界。
3. **Given** 鼠标下没有任何可采集的主语言字符串，**When** 悬停，**Then** 显示无法翻译类提示，且不进行 OCR。

---

### Edge Cases

- 世界中的告示牌、头顶名字、漂浮文字仍不参与定格取词（与 006 一致）。
- 多个相邻翻译键视觉上连成一大段时，只处理当前命中键对应的单元，不自动合并。
- 句末标点切分时，尽量避免把 `1.21` 或常见英文缩写误切；无法完美时优先少送字而不是多送整段。
- 对照语言方向：主语言 `en_us` ↔ `zh_cn`；其它主语言可定格但不做本特征提示（与 006 一致）。
- 取词仅英→中；主语言为中文时取词模式对中文词不提供英译（本特征范围外）。
- 定格、输入隔离、冲突模组停用等行为继承 006；本特征只扩展提示内容与模式。
- 机翻结果应缓存同一源文本，避免鼠标微抖重复请求。
- Polyglot Tooltip 或 Language Reload 已安装时，定格整体不生效（继承 006）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 定格期间 MUST 提供取词与对照段两种模式；默认 MUST 为取词。玩家 MUST 能用快捷键与浮窗按钮切换，二者状态 MUST 一致。
- **FR-002**: 取词模式 MUST 对光标下英文词查询附带常见词词典；命中则显示中文释义。本特征 MUST NOT 提供中→英取词。
- **FR-003**: 取词模式下，即使存在语言包整段对照，MUST 只显示词义，MUST NOT 自动弹出整段对照。
- **FR-004**: 对照段模式下，若存在语言包翻译单元对照，MUST 显示对照语言下该单元全文（可含多句），MUST NOT 按标点截断该对照。
- **FR-005**: 对照段模式下若无语言包对照，MUST 按句末标点取光标所在单句；扩展翻译开启时 MUST 可请求本机机翻显示该句。
- **FR-006**: 玩家聊天、改名、手写书页等可采集的可见 UGC，在无语言包对照时 MUST 允许走扩展机翻路径（受配置开关约束），覆盖 006 中「玩家文字永不提示」的限制。
- **FR-007**: 扩展翻译 MUST 为可选客户端配置项，默认开启；MUST NOT 作为模组加载硬依赖。关闭后 MUST NOT 发起本机机翻请求。
- **FR-008**: 扩展翻译开启且本机服务失败或超时或未安装时，对需要机翻的悬停 MUST 每次显示错误提示，直到玩家关闭该配置项。
- **FR-009**: 机翻请求 MUST 仅指向本机地址；单词与整句 MUST 使用规格固定的默认模型标识（单词 `qwen2.5:1.5b`，整句 `qwen2.5:3b`），不向玩家开放任意模型名作为常规选项。
- **FR-010**: 需要机翻时 MUST 显示加载态，并 MUST 有超时与失败文案。
- **FR-011**: 无法从绘制路径取得主语言可见字符串时，MUST 提示无法翻译；MUST NOT 使用 OCR。
- **FR-012**: 附带词典 MUST 来自可再分发许可的数据（默认 ECDICT MIT 频次截断）；MUST NOT 再分发商业 COCA 词表。分发 MUST 附带许可声明。
- **FR-013**: 成品字符串 MUST NOT 被反查为翻译键以伪造语言包对照（继承 006）；语言包对照仍须来自翻译组件/键。
- **FR-014**: 本特征 MUST 提供客户端配置能力（至少含扩展翻译开关）；配置变更 MUST 在客户端生效且无需重装模组。
- **FR-015**: 世界投影文字（告示牌、头顶名、漂浮字）MUST NOT 被取词。冲突模组存在时定格 MUST NOT 生效（继承 006）。

### Key Entities

- **LookupMode**: 取词或对照段；定格会话内可变，默认取词。
- **VisibleSpan**: 定格画面上可命中的可见字符串及其矩形（可来自翻译组件或字面量）。
- **TranslationUnitCounterpart**: 某一翻译组件/键在对照语言下的全文。
- **DictionaryEntry**: 英文词形到中文释义的离线条目。
- **MachineTranslationRequest**: 对本机服务的单词或单句请求（含加载/超时/失败/缓存）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 定格后默认取词模式下，对词典内常见英文词，悬停后一秒内出现中文释义（本机词典，无网络）。
- **SC-002**: 对照段模式下，对有中英语言包的任务/按钮类多句文案，悬停后显示整段对照而非单句截断。
- **SC-003**: 扩展翻译关闭后，不再出现本机机翻错误提示；语言包对照与词典命中仍可用。
- **SC-004**: 本机翻译服务未安装时，模组仍能进入世界；扩展翻译保持开启时，需机翻的悬停每次都能看到失败提示。
- **SC-005**: 无可见字符串可采集时，玩家看到无法翻译提示，且过程中不出现 OCR 或截图像素识别步骤。
- **SC-006**: 取词与对照段模式可通过快捷键与浮窗按钮切换，切换后下一次悬停行为符合当前模式。

## Assumptions

- 定格开关、画面冻结、输入隔离沿用 006 实现；本特征扩展命中内容与提示策略。
- 「本机翻译服务」指玩家自行安装的 Ollama 及指定模型；模组只做 HTTP 客户端。
- 主语言仅 `en_us` / `zh_cn` 时提供本特征提示。
- 词典截断规模以包体可接受为度（约高频数万词级），具体条目数在计划中确定。
- 006 规格中与本特征冲突的 FR（禁止机翻、禁止 UGC 提示）以本特征为准；未冲突部分继续有效。
- 设计备忘见 `docs/plan/Ollama集成.md`；与本规格冲突时以本规格为准。
