# Contract: 定格扩展取词与对照段 / 机翻

玩家可见行为。实现细节见 plan/research。本契约覆盖并修正 006 中与机翻、UGC 冲突的条款。

## 模式

- 定格后默认 **取词**。
- 快捷键与浮窗按钮切换 **取词 ↔ 对照段**，状态一致。
- 结束定格后提示消失；再次定格仍默认取词（除非实现选择记住模式——规格默认不要求记住）。

## 取词模式

- 光标下英文词 → 离线词典中文释义。
- 词典未命中且扩展翻译开 → 本机单词模型；加载 / 超时 / 失败均有文案。
- 扩展翻译关 → 未命中则不机翻（可无提示或简短「无释义」，不得报 Ollama 错误）。
- 即使有语言包整段对照，也不自动弹出整段。

## 对照段模式

- 有语言包翻译单元 → 对照语言 **全文**（可多句）。
- 无对照 → 句末标点单句；扩展翻译开则本机整句模型。
- 玩家聊天、改名、手写书页等可采集 UGC：无包时走机翻路径（受开关约束）。

## 扩展翻译配置

- 客户端配置项，默认开。
- 关：不发起本机机翻。
- 开且服务失败：每次需要机翻的悬停都显示错误，直到玩家关闭配置。
- 模组加载不依赖本机服务。

## 无法翻译

- 无可见主语言字符串 → 「无法翻译」类提示。
- 不做 OCR。

## 不变（继承 006）

- F3+K（或已绑定键）定格；输入隔离；世界投影文字不取。
- 不反查成品字符串为翻译键。
- Rival 冲突模组存在时定格不生效。
- 仅 `en_us` / `zh_cn` 主语言提供本特征提示。
