# Data Model: JEI 中英与拼音搜索

## PinyinTokens

纯文本结果，不引用游戏对象。

| 字段 | 规则 |
| --- | --- |
| full | 汉字序列的小写无声调连续全拼。没有汉字时为空，调用方不索引。 |
| initials | 与 full 同一个汉字序列的首字母，小写。 |

校验：

- 不包含声调数字、空格或分隔符。
- 非汉字不产生读音。
- 多音字只保留库返回的第一个读音。

## ItemSearchTerms

一个物品在一次资源加载周期内的搜索词。

| 字段 | 规则 |
| --- | --- |
| itemId | 物品标识，用于把词送回 JEI 里对应的条目。 |
| chineseName | `LanguageTexts` 的中文名。缺失则整体不产生拼音。 |
| englishName | 英文名。缺失则英文查询不能靠本模组命中，已有的原版英文索引仍然有效。 |
| pinyin | 由 chineseName 生成。可缺失。 |

关系：依赖 `LanguageTexts` 的当前表，不依赖当前主语言。主语言切换不改变已生成的词。

## 状态

索引与语言表一起处于未就绪或就绪。未就绪时不向 JEI 追加词，JEI 自己的原版搜索保持原样。就绪后词组不变，直到下一次资源重载。
