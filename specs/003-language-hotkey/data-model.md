# Data Model: 中英主语言快捷切换

## LanguageCycle

无状态规则。

| 输入 | 输出 |
| --- | --- |
| `zh_cn` | `en_us` |
| `en_us` | `zh_cn` |
| 其他任何代码，包括空 | `zh_cn` |

不保存第三种语言，不生成更长的循环。

## SwitchBinding

| 字段 | 规则 |
| --- | --- |
| customKey | 玩家在控制设置里保存的单键。未设置时为空。 |
| defaultChord | 固定为 F3+J，仅在 customKey 为空时生效。 |

聊天输入界面处于打开状态时，本次按键被丢弃，不改变语言。

## ActiveLanguage

| 字段 | 规则 |
| --- | --- |
| code | 游戏选项里的当前语言代码。按键成功后只可能变成 `zh_cn` 或 `en_us`。 |
| installedTexts | 指向 `LanguageTexts` 里同代码的那一份。按键不复制文本。 |
| saved | 成功切换后写回原版选项。下次启动由游戏自己恢复这个代码，001 再加载两套表。 |

## 状态

- 启动后、第一次按键前：选项是什么语言，界面就是什么语言。两套表已经在 `LanguageTexts` 里。
- 按键被接受：按 `LanguageCycle` 前进，安装对应表，刷新契约里的界面，保存选项。
- 目标语言表不可用：保持当前状态。
- 资源重载：两套表由 001 重建。当前代码不变。
