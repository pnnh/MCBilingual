# Feature Specification: 中英主语言快捷切换

**Feature Branch**: `003-language-hotkey`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "游戏启动时就加载简体中文和英文两套文案。按一个全局快捷键在这两种主语言之间切换，例如 F3+J。不同于原版语言切换，不走完整的语言重载等待。只需要这两种语言。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一次按键换掉眼前的主语言 (Priority: P1)

玩家在游戏中或打开着界面时按下快捷键。按钮、标题、物品名称和菜单从简体中文变为英文，或从英文变为简体中文。不出现资源重载进度，也不回到标题画面。再按一次，切回刚才的语言。

**Why this priority**: 这是本功能的全部用户价值。切换如果要等待完整重载，就和原版语言菜单没有差别。

**Independent Test**: 中英语言包都已加载时，站在世界里按一次默认快捷键，再打开背包。物品名和界面文字已经是另一种语言。再按一次后恢复。过程中没有资源重载画面。

**Acceptance Scenarios**:

1. **Given** 当前主语言是简体中文，**When** 玩家按下切换快捷键，**Then** 背包、暂停菜单和物品名称改为英文，且不出现资源重载画面。
2. **Given** 刚刚切到英文，**When** 玩家再按一次，**Then** 上述文字回到简体中文。
3. **Given** 背包或暂停菜单已经打开，**When** 玩家按快捷键，**Then** 当前界面上的文字随之更新，不必先关闭界面。
4. **Given** 玩家完成切换，**When** 继续游戏，**Then** 仍停留在原来的世界和界面，不被送回标题画面。

---

### User Story 2 - 启动时两套文案都已就绪 (Priority: P2)

进入世界后，玩家第一次悬停物品就能看见另一种语言的名称，第一次按快捷键也能立刻切过去。不需要先打开语言菜单，也不需要为了「预热」另一种语言而切两次。

**Why this priority**: 用户明确要求启动时加载两种文案。若第二次语言等到快捷键才读取，第一次切换就会退回慢速重载。

**Independent Test**: 冷启动并进入世界，不打开语言设置。先看一个中英不同的物品提示框，再按快捷键。第二语言行在按键前已经正确，按键后主语言立即改变。

**Acceptance Scenarios**:

1. **Given** 客户端刚刚进入世界，且尚未按过切换键，**When** 玩家悬停中英名称不同的物品，**Then** 另一语言名称已经出现在标题下。
2. **Given** 同一次启动，**When** 玩家第一次按下快捷键，**Then** 主语言在一秒内切换完成，没有资源重载画面。

---

### User Story 3 - 选择被记住，且只有这两种语言 (Priority: P3)

玩家切到英文后退出游戏。下次启动直接以英文为主语言，中文仍作为已经加载的另一种语言。快捷键不会切到第三种语言。

**Why this priority**: 只要求中英，并且切换应当像游戏自己的语言设置一样留下来。

**Independent Test**: 切换到非启动语言，完全退出客户端再进世界。主语言保持上次的选择。连续按快捷键只在中文和英文之间交替。

**Acceptance Scenarios**:

1. **Given** 玩家把主语言切到英文并退出，**When** 下次进入世界，**Then** 主语言仍是英文，提示框第二行仍是中文。
2. **Given** 玩家连续按下快捷键，**When** 观察界面语言，**Then** 只在简体中文和英文之间交替。
3. **Given** 启动时游戏语言不是中文也不是英文，**When** 玩家第一次按快捷键，**Then** 主语言变为简体中文；再按变为英文；之后只在这两种之间交替。按键之前不改写原来的语言。

---

### Edge Cases

- 默认快捷键是按住调试键再按 J。玩家可以在控制设置里改成其他按键。改键后旧组合不再切换语言。
- 快捷键在游戏中、背包中和暂停菜单中都生效。聊天输入框打开并正在输入时不抢按键。
- 缺少其中一种语言包时，快捷键仍可按下。已有的那种语言正常显示；缺失的语言不制造翻译键，提示框按双语规格省略缺失行。
- 已经打开的按钮、标题和物品名必须更新。已经打开的书和进度界面也要更新。不保证每一个第三方界面都在不关闭的情况下刷新；关闭后重新打开必须是新语言。
- 告示牌和文本展示若当前能看见，切换后应显示新语言。做不到即时刷新时，重新打开或重新靠近后必须正确。
- 切换不重新下载语言包，也不重载材质、模型和音效。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 客户端启动并完成资源加载后，MUST 同时持有简体中文和英文两套文案。
- **FR-002**: 玩家 MUST 能用一个快捷键在这两种主语言之间切换。
- **FR-003**: 默认快捷键 MUST 是按住调试键再按 J。玩家 MUST 能在控制设置中更改。
- **FR-004**: 快捷键 MUST 在世界中、背包打开时和暂停菜单中生效，MUST NOT 在聊天输入过程中触发。
- **FR-005**: 切换 MUST 改变玩家眼前跟随游戏语言的文字，包括菜单、按钮、标题和物品名称。
- **FR-006**: 切换 MUST NOT 显示资源重载画面，MUST NOT 把玩家送回标题画面。
- **FR-007**: 从按下到当前背包或暂停菜单文字完成更新，MUST 在一秒以内。
- **FR-008**: 切换后的主语言 MUST 写入游戏的语言设置，下次启动仍然生效。
- **FR-009**: 下次启动时另一种语言也 MUST 已经加载，而不是等到下一次按键。
- **FR-010**: 快捷键 MUST NOT 切到中英以外的语言。
- **FR-011**: 启动时语言若不是中英，MUST 保持该语言，直到玩家第一次按下快捷键；第一次进入简体中文，之后只在中英之间交替。
- **FR-012**: 文案 MUST 来自已加载资源包或其他模组。本模组 MUST NOT 自带翻译文件。
- **FR-013**: 本功能 MUST NOT 要求 PolyglotTooltip 或 Language Reload。
- **FR-014**: 缺少一种语言包时，模组 MUST 仍能进入世界，且不把翻译键当成该语言的显示文本。

### Key Entities

- **主语言**: 当前界面实际使用的语言。本功能里只能是简体中文或英文；启动时若游戏原来使用其他语言，则保持到第一次按键。
- **预加载文案**: 启动后就留在内存里的中文语言表和英文语言表。
- **快捷键**: 玩家可改的切换操作。默认是调试键加 J。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 进入世界后按一次快捷键，背包和暂停菜单的文字换成另一种语言；再按一次恢复。两次都没有资源重载画面，玩家不被送回标题画面。
- **SC-002**: 每次切换在一秒内反映到已经打开的背包或暂停菜单上。
- **SC-003**: 冷启动后、第一次按键之前，中英名称不同的物品已经显示另一语言行。
- **SC-004**: 退出并重新进入后，主语言与退出前一致，另一语言行仍然可用。
- **SC-005**: 连续按 10 次，界面语言只在简体中文和英文之间交替。
- **SC-006**: 卸下其中一种语言包后，客户端仍能进入世界。

## Assumptions

- 「切换显示的主语言」指跟随游戏语言的整套界面文字，包括菜单、按钮、标题和物品名。不是只改提示框哪一行当标题、菜单却留在原语言。双语提示框的另一行始终是这两种语言里当前没作为主语言的那一种；该行的规则见 `001-bilingual-tooltips`。
- 本阶段没有第三种显示模式，快捷键不在「只显示主语言 / 只显示副语言 / 双语」之间循环。双语名称行保持可用。
- 默认按键沿用用户举例的调试键加 J，并允许在控制设置里修改。
- 不重做原版语言列表，不提供多语言后备栈，不自动检测操作系统语言。
- 书、进度、看得见的告示牌和文本展示属于应刷新的原版界面。其他模组的自定义界面只要求关闭再打开后是新语言。
- I18nUpdateMod3 与 Minecraft-Mod-Language-Package 是推荐语言来源，不是必装依赖。
