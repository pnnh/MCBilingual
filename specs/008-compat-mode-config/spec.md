# Feature Specification: 三方模组兼容模式

**Feature Branch**: `008-compat-mode-config`

**Created**: 2026-11-06

**Status**: Draft

**Input**: User description: "客户端配置是一个默认为空的数组，每项是第三方模组 id 和 Full、Generic、Off 之一。Full 启用专为该模组写的兼容。Generic 不执行这些专用兼容，接近原版的文本仍可能显示双语。Off 不在该模组自己的界面和覆盖层上加载本模组的任何功能，原版内容不受影响。已有第三方兼容代码都要有门禁。某个第三方初始化失败时跳过它并写客户端日志，不影响原版和其它集成。"

## Clarifications

### Session 2026-11-06

- Q: Off 按什么边界生效？JEI 和 Jade 大多画在原版界面上。 → A: 按该模组自己的界面和覆盖层。同一页上的原版格子和原版提示照常。
- Q: Off 时 F3+J 和 F3+K 怎么办？ → A: 热键仍然全局可用。F3+J 照常切换整个客户端语言。F3+K 不读取被设为 Off 的模组自己画出的文字，原版文字仍可冻结查看。
- Q: 配置键用显示名还是 mod id？未写入的模组呢？ → A: 键是 mod id。未写入的模组按 Full。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 只有原版时一切照常 (Priority: P1)

玩家只安装 Minecraft Java 版 1.21.1 和 NeoForge，不安装任何第三方模组。配置保持默认空列表。原版物品提示的双语、语言切换和冻结查看都可用，客户端能进入世界。

**Why this priority**: 原版是第一优先。配置和第三方兼容都不能变成新的启动条件。

**Independent Test**: 不放入 Jade、JEI、应用能源、Integrated Terminals。空配置进入世界，看原版物品提示、按一次语言切换热键、对原版界面文字做一次冻结查看。

**Acceptance Scenarios**:

1. **Given** 未安装任何第三方模组且配置为空，**When** 玩家进入世界，**Then** 客户端进入世界，不因缺少第三方模组而失败。
2. **Given** 同上，**When** 玩家查看原版物品提示，**Then** 双语第二行仍按现有规则出现。
3. **Given** 同上，**When** 玩家切换语言或冻结查看原版界面文字，**Then** 这两项仍可用。

---

### User Story 2 - 默认启用已有的专用兼容 (Priority: P1)

配置为空，或某个已支持的模组没有被写进配置。该模组已安装时，现在已有的专用兼容保持启用：Jade 的第二行名称、JEI 的中英和拼音搜索、应用能源终端搜索、Integrated Terminals 终端搜索。

**Why this priority**: 空列表的意思是全部按 Full。加配置不能让现有玩家丢掉已经在用的兼容。

**Independent Test**: 空配置下分别装上这四个模组之一，重复该模组现有的双语或搜索检查。

**Acceptance Scenarios**:

1. **Given** 配置为空且安装了 Jade，**When** 玩家看向方块或实体，**Then** Jade 浮层仍有双语名称。
2. **Given** 配置为空且安装了 JEI，**When** 玩家用另一种语言或拼音搜索，**Then** 仍能找到对应物品。
3. **Given** 配置为空且安装了应用能源，**When** 玩家在 ME 终端用另一种语言或拼音搜索，**Then** 仍能找到对应物品。
4. **Given** 配置为空且安装了 Integrated Terminals，**When** 玩家在存储终端用另一种语言或拼音搜索，**Then** 仍能找到对应物品。

---

### User Story 3 - 关掉某一个模组的专用兼容 (Priority: P2)

玩家把某一个 mod id 设为 Generic。本模组不再执行专为那个模组写的兼容。其它模组和原版内容保持原样。如果那个模组自己用了接近原版的文本方式，双语仍可能出现；这不作为保证。

**Why this priority**: 玩家需要一条比“完全当这个界面不存在”更窄的退路，用来避开写坏的专用兼容，同时留着原版路径。

**Independent Test**: 只把 `jei` 设为 Generic，其它 id 不写。看 JEI 搜索不再接受另一种语言和拼音，再看原版背包里的物品提示仍然双语。对其余三个 id 各做一次同样的单点检查。

**Acceptance Scenarios**:

1. **Given** `jei` 为 Generic，**When** 玩家在 JEI 用另一种语言或拼音搜索，**Then** 不要求命中；JEI 自己的当前语言搜索仍可用。
2. **Given** `jei` 为 Generic，**When** 玩家在原版背包查看原版物品提示，**Then** 双语第二行仍在。
3. **Given** `jade` 为 Generic，**When** 玩家看向方块，**Then** 本模组不再为 Jade 写入第二行名称。原版物品提示不受影响。
4. **Given** `ae2` 为 Generic，**When** 玩家在 ME 终端搜索，**Then** 本模组不再为这个终端追加另一种语言或拼音。原版背包搜索和提示不受影响。
5. **Given** `integratedterminals` 为 Generic，**When** 玩家在存储终端搜索，**Then** 本模组不再为这个终端追加另一种语言或拼音。原版界面不受影响。
6. **Given** 只把其中一个 id 设为 Generic，**When** 玩家使用另一个仍为 Full 的模组，**Then** 那个模组的专用兼容仍然有效。

---

### User Story 4 - 在某个模组自己的界面上完全停用 (Priority: P2)

玩家把某一个 mod id 设为 Off。本模组不在那个模组自己画出的界面和覆盖层上加载任何功能。同一画面里由原版画出的格子和提示不受影响。语言切换热键仍然改变整个客户端的语言。冻结查看不读取这块被关掉的界面或覆盖层上的文字，原版文字仍可查看。

**Why this priority**: Generic 只撤专用代码。Off 是玩家明确不要本模组碰这个模组自己的界面。

**Independent Test**: `jei` 为 Off 时，打开带 JEI 物品列表的原版背包，确认列表、搜索框和 JEI 配方界面没有本模组的双语或额外搜索，再确认原版格子上的提示仍有双语。`jade` 为 Off 时只检查 Jade 浮层。`ae2` 和 `integratedterminals` 为 Off 时，检查它们的终端整页不再出现本模组功能，然后回到原版背包确认提示仍在。

**Acceptance Scenarios**:

1. **Given** `jei` 为 Off 且原版背包上画着 JEI 列表，**When** 玩家使用 JEI 列表、搜索框或配方界面，**Then** 这些 JEI 自己的区域没有本模组的双语提示、额外搜索或冻结查看。
2. **Given** 同上，**When** 玩家查看这个背包里原版格子上的原版物品提示，**Then** 双语第二行仍在，冻结查看仍能读到原版文字。
3. **Given** `jade` 为 Off，**When** 玩家看向方块或实体，**Then** Jade 浮层上没有本模组的第二行，也不对该浮层做冻结查看。原版提示不受影响。
4. **Given** `ae2` 为 Off，**When** 玩家打开 ME 终端，**Then** 这一页上没有本模组的搜索追加、双语提示或冻结查看。
5. **Given** `integratedterminals` 为 Off，**When** 玩家打开存储终端，**Then** 这一页上没有本模组的搜索追加、双语提示或冻结查看。
6. **Given** 上述任一 id 为 Off，**When** 玩家按语言切换热键，**Then** 整个客户端的语言仍然切换，包括之后打开的原版界面。
7. **Given** 只把一个 id 设为 Off，**When** 玩家使用另一个仍为 Full 的模组，**Then** 那个模组的专用兼容仍然有效。

---

### User Story 5 - 某一个第三方初始化失败时跳过它 (Priority: P1)

某个已安装的第三方模组因为版本或其它兼容问题，导致本模组为它准备的兼容在初始化时失败。客户端继续启动。日志写明是哪一个模组失败，以及失败原因。原版功能继续可用。其它没有失败的第三方兼容继续可用。玩家保存在配置里的选择不被改写。

**Why this priority**: 这是宪法里的运行前提。一个可选模组不能带走整个客户端。

**Independent Test**: 用一个会让某一条兼容初始化失败的第三方版本启动，进入世界，读最新日志，再检查原版提示和另一条未失败的兼容。

**Acceptance Scenarios**:

1. **Given** 某一条第三方兼容初始化失败，**When** 客户端启动，**Then** 游戏仍能进入世界。
2. **Given** 同上，**When** 玩家查看客户端日志，**Then** 有一条记录写出失败的 mod id 和失败原因。
3. **Given** 同上，**When** 玩家查看原版物品提示，**Then** 双语仍然可用。
4. **Given** 另一条兼容没有失败且配置为 Full，**When** 玩家使用那个模组，**Then** 它的专用兼容仍然可用。
5. **Given** 失败发生时配置里已有该 mod id，**When** 启动完成，**Then** 配置文件中的该项保持玩家写下的值。

---

### Edge Cases

- 空列表、缺少配置、以及从未打开过配置界面，三者都表示每一个 mod id 都是 Full。
- 未出现在列表中的 mod id 是 Full，即使那个模组已安装。
- 列表里的 mod id 对应的模组这次没有安装：保留这一项，不报错，也不因此停止启动。
- 同一个 mod id 出现多次：后写的一项生效，日志说明一次以前一项被忽略。
- 大小写和首尾空格不改变 mod id。`JEI` 和 `jei` 是同一项。
- 无法识别的取值：日志说明这一项无效，该 mod id 按 Full 运行。
- 玩家保存配置后回到游戏即可生效，不需要重启客户端，也不需要重新进入世界。
- Generic 不保证那个模组里一定看得到或一定看不到双语。它只保证专用兼容不再执行。
- Off 只覆盖该模组自己画出的界面和覆盖层。JEI 画在原版背包上时，原版格子不算 JEI 的界面。
- 应用能源终端和 Integrated Terminals 终端是它们自己的整页界面。Off 时，这一页上的本模组功能都停用。
- 冻结查看在 Off 的界面或覆盖层上不读取该模组画出的文字。同一屏上的原版文字仍可读取。
- 语言切换不受 Full、Generic、Off 影响。
- 同时安装 Polyglot Tooltip 或 Language Reload 时，本模组仍然整体停用。这份列表不能把整体停用重新打开。
- 初始化失败的日志每个模组每次启动记一次，不按物品或每次绘制重复刷屏。
- 本阶段要装上门禁的专用兼容只有已经存在的四条：`jade`、`jei`、`ae2`、`integratedterminals`。列表可以写下其它 id，但没有对应兼容时没有额外效果。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 客户端配置 MUST 提供一份默认为空的列表。每一项是一个 mod id，以及 Full、Generic、Off 三个取值之一。
- **FR-002**: 玩家 MUST 能在本模组的客户端配置界面查看和修改这份列表，并在回到游戏后生效，无需重启客户端。
- **FR-003**: 空列表、缺失配置，以及未列入的 mod id MUST 按 Full 处理。
- **FR-004**: Full MUST 启用当前已经为该 mod id 实现的专用兼容。
- **FR-005**: Generic MUST 不执行专为该 mod id 写的兼容。原版文本路径 MUST 继续工作。不要求该模组内部一定显示或一定不显示双语。
- **FR-006**: Off MUST 不在该模组自己的界面和覆盖层上加载本模组的双语提示、专用搜索、Jade 第二行或冻结查看。同一画面中的原版内容 MUST 保持可用。
- **FR-007**: 语言切换 MUST 在任何一项为 Generic 或 Off 时仍然切换整个客户端的语言。
- **FR-008**: 冻结查看 MUST 在 Off 的界面或覆盖层上跳过该模组自己画出的文字，并 MUST 仍能查看原版文字。Generic MUST 不因此禁止冻结查看那一页上的可见文字。
- **FR-009**: 已实现的 `jade`、`jei`、`ae2`、`integratedterminals` 四条专用兼容 MUST 各自遵守该 id 的 Full、Generic、Off。改一个 id MUST NOT 改变另一个 id。
- **FR-010**: 未安装任何第三方模组时，原版双语提示、语言切换和冻结查看 MUST 可用，客户端 MUST 能进入世界。
- **FR-011**: 某一条第三方兼容初始化失败时，本模组 MUST 跳过该模组，在客户端日志写出 mod id 和失败原因，并继续提供原版功能以及其它未失败的兼容。
- **FR-012**: 初始化失败 MUST NOT 改写玩家已保存的配置项。
- **FR-013**: 无效取值 MUST 被记入日志，并使该项按 Full 运行。重复的 mod id MUST 以后写的一项为准，并记一条日志。
- **FR-014**: 列表中的 mod id 在本次没有安装时 MUST NOT 阻止启动，也 MUST NOT 因此重复报错。
- **FR-015**: Polyglot Tooltip 或 Language Reload 导致的整体停用 MUST 优先于这份列表。

### Key Entities

- **兼容项**: 一个 mod id 和三个模式之一。mod id 不区分大小写，比较前去掉首尾空格。
- **兼容列表**: 有序的兼容项集合。默认空。空和未列出的 id 都表示 Full。
- **界面归属**: 一段界面或覆盖层属于画出它的那个模组。原版画出的格子和提示属于原版，即使旁边画着另一个模组的列表或浮层。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 只安装游戏和 NeoForge、配置为空时，玩家能进入世界，并在一次会话内完成原版提示、语言切换和冻结查看三项检查。
- **SC-002**: 配置为空时，四个已支持模组各自的现有双语或搜索行为与加这份配置之前一致。
- **SC-003**: 只把一个 mod id 改成 Generic 或 Off 后，玩家不重启客户端，下一次打开相关界面就能看到该项生效，且另外三个 id 的行为不变。
- **SC-004**: `jei` 为 Off 时，玩家在同一次打开的背包里能同时确认两件事：JEI 自己的列表和配方区域没有本模组功能，原版格子的双语提示还在。
- **SC-005**: 一条兼容初始化失败时，最新客户端日志里有且仅有一条该模组的失败记录，玩家仍能进入世界并使用原版提示。
- **SC-006**: 任一 id 为 Off 时，玩家按一次语言切换热键，原版界面的语言随后改变。冻结查看不解释该模组自己画出的文字。

## Assumptions

- 玩家写下的键是 mod id，不是模组显示名。四个现有 id 是 `jade`、`jei`、`ae2`、`integratedterminals`。
- Full、Generic、Off 是配置里保存和显示的三个取值。界面上可以在取值旁边给一句中文说明。
- “回到游戏后生效”指保存配置并关闭配置界面之后。不要求玩家退出世界或重启游戏。
- Generic 留下的“也许仍能双语”只来自原版文本路径碰巧被那个模组使用。规格不把这种情况写成必须出现，也不把它写成缺陷。
- 初始化失败的跳过，和玩家把某一项设成 Generic 或 Off，是两件独立的事。失败不修改配置。
- 本阶段不为殖民地或其它尚未实现专用兼容的模组新写兼容。它们被写入列表时按“没有专用兼容”处理。
- 整体停用规则维持现状：遇到 Polyglot Tooltip 或 Language Reload，本模组不改提示、搜索或语言。
- NeoForge 的要求版本是 21.1.251 以及同一条 API 上的更新版本。用户原文里的 “2.251.1” 按这个版本理解。
