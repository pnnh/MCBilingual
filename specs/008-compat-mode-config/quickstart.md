# Quickstart: 三方模组兼容模式

单测不代替下面的客户端观察。实现完成后先跑：

```bash
./gradlew test --offline
```

预期新增解析和门禁测试通过，已有 JEI 测试仍通过。然后 `./gradlew runClient`。开发用的 Jade、JEI、应用能源和 Integrated Terminals 可以留在运行目录里。发布包不包含它们。

配置在模组列表里打开本模组的客户端配置。列表默认是空的。一行写成 `jei=Generic` 这种形式。保存后回到游戏，不重启。

## 原版

1. 临时移走第三方模组后再启动。空配置进入世界。
2. 原版物品提示仍有灰色的另一种语言名称。
3. 按一次语言切换热键，界面语言改变，没有资源重载画面。
4. 对原版界面文字做一次冻结查看，能看到另一种语言。

## 空列表等于 Full

装回四个模组，列表保持为空。

1. Jade 看向方块，浮层有第二行名称。
2. JEI 用另一种语言和一次全拼各搜到原版物品。
3. 应用能源 ME 终端用另一种语言搜到物品。
4. Integrated Terminals 存储终端的物品页和流体页，普通名称仍接受另一种语言。`@` 开头的词不被放宽。

## 只关一个模组

1. 写入 `jei=Generic` 并保存。JEI 用另一种语言或拼音不再由本模组命中。原版背包格子的双语提示还在。Jade 仍有第二行。
2. 改成 `jei=Off` 并保存。JEI 列表、搜索框和配方界面没有双语提示、额外搜索和冻结查看。同一背包里原版格子的提示仍有双语，冻结查看仍能点中原版文字。
3. 按语言切换热键，整个客户端的语言仍然切换。
4. 删掉 JEI 那一行，改成 `jade=Off`。Jade 浮层没有第二行，冻结查看不解释浮层上的字。原版提示仍在。
5. 分别把 `ae2=Off` 和 `integratedterminals=Off` 各测一次。终端整页没有本模组的搜索、提示和冻结查看。回到原版背包后提示恢复。
6. 同时写 `jei=Off` 和 `ae2=Full`。JEI 按 Off，应用能源终端搜索仍追加另一种语言。

## 坏配置和失败

1. 写 `jei=Sometimes`。日志说明这项无效。JEI 仍按 Full 工作，客户端进入世界。
2. 写两行 `jei=Generic` 和 `jei=Off`。后一行生效，日志说明前一行被忽略。
3. 写一个没有安装的 mod id。启动不报错。
4. 专用兼容若在启动时失败，最新日志里该 mod id 只有一条失败记录。原版提示仍可用，配置文件里的原文还在。

同类语言模组不在这张列表里测试。Polyglot Tooltip 或 Language Reload 存在时，本模组仍整体停用。
