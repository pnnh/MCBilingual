# Data Model: 三方模组兼容模式

## 兼容模式

三个取值：`Full`、`Generic`、`Off`。比较时忽略大小写和首尾空格。

没有记录、配置缺失、空列表，都读成 `Full`。无法识别的取值也读成 `Full`，并记一条日志。

## 兼容项

| 字段 | 规则 |
| --- | --- |
| mod id | 去掉首尾空格后整段转成小写。空字符串丢弃。 |
| 模式 | 上表三个取值之一。 |

同一 mod id 出现多次时，列表里靠后的一项生效。被盖住的前一项记一条日志。

没有安装的 mod id 留在列表里，不因此报错，也不阻止启动。

## 兼容列表

有序的兼容项。默认空。

运行时是一张 mod id 到模式的快照。查找不到的 id 返回 `Full`。配置加载和重载时整张替换，不在绘制中改某一项。

玩家保存的原文不被初始化失败改写。

## 界面归属

某一刻的归属是下面两者的并集：

- 当前打开的 Screen 的类所归属的 mod id。没有 Screen，或类不在任何模组文件里，则这一路为空。
- 绘制栈里当前压入的 mod id。JEI 物品列表和 Jade 浮层用这一路。栈在每帧开始清空。

原版背包的 Screen 归属不是 `jei`。只有绘制走进 JEI 列表或提示时，栈里才有 `jei`。

## 初始化失败

每个 mod id 至多一条记录：失败原因。一旦记下，该 id 的专用兼容不再执行。共用的提示、语言切换和冻结查看不因这条记录关闭，除非该 id 的模式本来就是 Off 并且当前界面属于它。

记录只活在这一次客户端运行里，不写进配置。

## 状态

1. 启动：列表为空或尚未加载，全部按 Full。同类语言模组已安装时，列表可以加载，但所有功能仍停用。
2. 配置加载或重载：用新快照替换旧快照。下一次界面绘制使用新快照。
3. 某条专用兼容失败：给该 mod id 记下失败。模式值不变。
4. 关闭客户端：失败记录消失。列表留在配置文件里。
