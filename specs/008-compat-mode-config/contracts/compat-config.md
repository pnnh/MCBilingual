# Contract: 客户端兼容列表

玩家打开本模组的客户端配置时：

1. 有一份列表，默认没有条目。说明文字同时给出中文和英文，并写出三个取值：`Full`、`Generic`、`Off`。
2. 每一项是一行 `modid=模式`。mod id 去掉首尾空格并忽略大小写。`JEI` 和 `jei` 是同一项。
3. 空列表、没有这个配置、以及没有出现的 mod id，都按 `Full`。
4. 同一 mod id 写了多次时，后写的一项生效。日志说明前一项被忽略。
5. 模式不是这三个取值时，日志指出这一项无效，该项按 `Full`。客户端仍能进入世界。
6. 列表里的 mod id 这次没有安装时，不报错，不阻止启动。
7. 玩家在配置界面保存并回到游戏后，下一次打开相关界面就使用新列表。不需要退出世界或重启客户端。
8. 某一条专用兼容初始化失败时，配置文件里的对应项保持玩家写下的文字。

Polyglot Tooltip 或 Language Reload 已安装时，这份列表仍然可以编辑和保存。它不能重新打开本模组的提示、搜索或语言切换。
