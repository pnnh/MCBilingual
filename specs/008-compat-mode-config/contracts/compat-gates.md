# Contract: 兼容门禁

同类语言模组未安装，且客户端已经进入世界时：

1. `Full` 保持该 mod id 今天已有的专用行为。空列表下，Jade 第二行、JEI 中英和拼音搜索、应用能源终端搜索、Integrated Terminals 物品页和流体页的普通名称搜索都仍在。
2. `Generic` 不执行专为该 mod id 写的兼容。JEI 不再为搜索追加另一种语言或拼音。Jade 不再写入第二行。应用能源和 Integrated Terminals 不再放宽终端名称条件。原版物品提示仍有双语第二行。
3. `Off` 包含 `Generic` 的停止范围。另外，该模组自己的界面或覆盖层上不再出现本模组的双语提示和冻结查看。
4. JEI 为 `Off` 时，物品列表、搜索框和配方界面没有本模组功能。同一背包里原版格子的提示仍有双语，冻结查看仍能读到原版文字。
5. Jade 为 `Off` 时，只停 Jade 浮层上的第二行和针对该浮层文字的冻结查看。原版提示不受影响。
6. 应用能源或 Integrated Terminals 为 `Off` 时，它们的终端整页没有本模组的搜索追加、双语提示和冻结查看。回到原版背包后，原版提示仍在。
7. 只改一个 mod id 时，另一个仍为 `Full` 的模组保持它的专用兼容。
8. 语言切换热键在任何一项为 `Generic` 或 `Off` 时仍切换整个客户端的语言。
9. 冻结查看在 `Generic` 下仍可读该模组界面上的可见文字。在 `Off` 下不读该模组自己画出的文字。
10. 某一条专用兼容初始化失败时，日志有一条该 mod id 和失败原因。之后这条专用兼容不再执行。原版提示和其它未失败且为 `Full` 的兼容继续可用。

未安装任何第三方模组时，原版提示、语言切换和冻结查看可用，客户端能进入世界。
