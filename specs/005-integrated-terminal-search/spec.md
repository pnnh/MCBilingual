# Feature Specification: 集成终端的中英与拼音搜索

**Feature Branch**: `005-integrated-terminal-search`

**Created**: 2026-10-23

**Status**: Draft

**Input**: User description: "为当前模组适配 integratedterminals-1.21.1-neoforge-1.10.0 的集成终端搜索界面，支持中文、英语和拼音搜索。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在存储终端里用中文、英文或拼音找物品 (Priority: P1)

玩家打开集成终端的存储终端，物品页里已经存着物品。无论当前主语言是中文还是英文，玩家都可以用物品的中文名、英文名、无声调全拼或首字母找到它。终端里看到的名称仍是当前主语言，不出现拼音。

**Why this priority**: 这个搜索框只认当前显示出来的名称。已有的物品清单搜索和其它模组的终端搜索都不会作用到这里。这是玩家点名的界面。

**Independent Test**: 开发用的客户端装有集成终端 1.10.0、它打开存储终端所需的配套、中文文案和本模组。用创造模式或管理员命令放好一个能看见物品的存储终端，存入一个两边语言都有名称的物品，分别用另一种语言的名称、全拼和首字母搜索。

**Acceptance Scenarios**:

1. **Given** 存储终端物品页里有一个中文名和英文名都存在的物品，且当前主语言是英文，**When** 玩家输入它的中文名，**Then** 该物品出现在结果中。
2. **Given** 同一终端、同一物品，且当前主语言是中文，**When** 玩家输入它的英文名，**Then** 该物品出现在结果中。
3. **Given** 物品中文名可以转成无声调全拼和首字母，**When** 玩家输入全拼或首字母，**Then** 该物品出现在结果中。
4. **Given** 玩家正在查看结果，**When** 看物品名称，**Then** 名称是当前主语言，拼音不出现在名称、提示框或搜索框里。
5. **Given** 玩家只用当前语言的名称搜索，**When** 查看结果，**Then** 终端原有的按当前名称查找仍然可用。

---

### User Story 2 - 搜索框原有的组合和前缀保持不变 (Priority: P1)

玩家仍然用终端自己的写法缩小范围。空格分开的每个词都要命中。竖线两边只要一边命中即可。以 `@`、`#` 或 `$` 开头的词仍按终端原来的含义查找，不改成按物品的中文、英文或拼音查找。

**Why this priority**: 只放宽普通名称时，不能把玩家已经会用的写法弄坏。

**Independent Test**: 在同一个存储终端里，用两个都该命中的词加空格搜索，用竖线搜索两个不同物品的名称，再用 `@` 加一个模组标识搜索。对照没有本功能时的结果。

**Acceptance Scenarios**:

1. **Given** 搜索框里用空格写了两个词，**When** 玩家查看结果，**Then** 只留下两个词都命中的物品。每个普通名称词可以用中文、英文、全拼或首字母命中。
2. **Given** 搜索框里用竖线分开两段，**When** 玩家查看结果，**Then** 命中任意一段的物品都会留下。
3. **Given** 一个词以 `@`、`#` 或 `$` 开头，**When** 玩家搜索，**Then** 结果与终端原来的查找一致，不因为中文、英文或拼音而多出物品。
4. **Given** 搜索框是空的，**When** 玩家查看物品页，**Then** 终端仍列出本来会列出的物品。
5. **Given** 玩家输入一段终端原本会拒绝的内容，**When** 搜索生效，**Then** 游戏不崩溃，也不因此把全部物品都列出来。

---

### User Story 3 - 没装这个模组或遇到同类语言模组时不添乱 (Priority: P2)

没安装集成终端时，本模组照常提供已有的提示、搜索和语言切换。同时安装 Polyglot Tooltip 或 Language Reload 时，本模组继续停用自己的行为，存储终端的搜索也不被本模组改写。

**Why this priority**: 这个搜索是加在已有行为上的。缺模组或冲突时，不能让客户端进不了世界。

**Independent Test**: 一次不装集成终端启动客户端。另一次装上 Polyglot Tooltip 或 Language Reload 之一，再打开存储终端搜索。

**Acceptance Scenarios**:

1. **Given** 没有安装集成终端，**When** 客户端启动并进入世界，**Then** 游戏不因缺少它而崩溃，已有的提示、物品清单搜索和语言快捷键仍可用。
2. **Given** Polyglot Tooltip 或 Language Reload 已安装，**When** 玩家在存储终端里搜索，**Then** 本模组不扩展该搜索，已有的停用说明仍出现，语言选项不被改写。

---

### Edge Cases

- 物品没有中文时，英文名和当前名称仍能找到它。不生成拼音，不把裸翻译键当作名称。
- 大小写不同、只输入名称的一部分时，命中规则与现有物品搜索一致。
- 便携存储终端若使用同一个搜索框，适用同一规则。
- 流体页里，一种流体在两种语言下都有名称时，普通名称搜索同样接受中文、英文、全拼和首字母。没有这些名称时，仍按终端当前名称查找。
- 能量页不增加中文、英文或拼音词。
- 切换主语言后，不必为了这次切换重新制作搜索词。搜索框里已输入的词仍然有效。列表上的名称按已有的语言切换规则更新。
- 中文文案来自外部。没有文案时游戏不崩溃。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 开发用的客户端必须能同时启动本模组与集成终端 1.21.1 NeoForge 1.10.0，以及打开存储终端并看见物品所需要的配套。这些模组都必须支持 Minecraft 1.21.1，以及 NeoForge 21.1.251 和同一条线上的更新版本。
- **FR-002**: 这些配套只用于开发会话。发布的本模组不得要求玩家安装集成终端或其配套，也不得把它们的内容打进发布包。
- **FR-003**: 存储终端物品页的普通名称搜索必须能用物品的简体中文名、英文名、无声调连续全拼和首字母命中该物品。当前主语言不改变这四种词。
- **FR-004**: 命中后显示出来的名称必须仍是当前主语言。拼音不得出现在终端名称、提示框或搜索框里。
- **FR-005**: 空格仍表示每一段都要命中，竖线仍表示任意一段命中。以 `@`、`#` 或 `$` 开头的词必须保持终端原来的查找，不得改用中文、英文或拼音。
- **FR-006**: 空搜索必须仍列出终端本来会列出的物品。终端原本会拒绝的输入不得导致崩溃，也不得因此列出全部物品。
- **FR-007**: 流体页的普通名称搜索，在该流体两种语言名称都存在时，适用与物品相同的四种词。能量页保持终端原来的查找。
- **FR-008**: 语言切换不得为了这次切换重新制作搜索词，也不得打开资源重载画面。
- **FR-009**: 未安装集成终端时，客户端必须仍能进入世界，已有功能保持可用。
- **FR-010**: 同时安装 Polyglot Tooltip 或 Language Reload 时，本模组必须继续停用自己的提示、搜索和语言切换，存储终端搜索也不被本模组扩展。
- **FR-011**: 只在简体中文和英文之间提供搜索词。某个物品或流体没有中文时，不得崩溃，不得用拼音冒充中文名。

### Key Entities

- **物品或流体的两种名称**: 在简体中文和英文下各自的可见名称。缺少的一种不补成翻译键。
- **搜索词**: 由两种名称得出的中文、英文、无声调全拼和首字母。只用于查找，不用于显示。
- **终端查询**: 玩家在集成终端搜索框中输入的文字。普通名称词使用搜索词。空格、竖线和 `@`、`#`、`$` 前缀保持终端原有含义。
- **存储终端**: 集成终端提供的、用来查看已存储物品的界面，包括使用同一搜索框的便携形式。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在装有集成终端 1.10.0 和中文文案的会话里，玩家对存储终端中一件两边都有名称的物品，用另一种语言的名称、全拼和首字母各搜索一次，三次都在当前结果里看到该物品。
- **SC-002**: 上述物品的可见名称是当前主语言。玩家在名称、提示框和搜索框里看不到拼音。
- **SC-003**: 空格、竖线以及 `@`、`#`、`$` 开头的搜索，结果与终端原本的含义一致。空搜索仍列出原来的物品。一段会被终端拒绝的输入不会让游戏崩溃，也不会列出全部物品。
- **SC-004**: 按下已有的语言快捷键后，不必重新制作搜索词，搜索框里已有的词仍然能找到该物品，且不出现资源重载画面。
- **SC-005**: 拿掉集成终端后，玩家仍能进入世界，原有提示、物品清单搜索和语言快捷键仍可用。
- **SC-006**: 同时安装 Polyglot Tooltip 或 Language Reload 时，存储终端搜索不被本模组扩展，已有的停用说明仍然出现。
- **SC-007**: 开发会话能在 Minecraft 1.21.1、NeoForge 21.1.251 上打开存储终端。发布包的许可证与加入这个开发模组之前相同。

## Assumptions

- 「集成终端搜索界面」指 Integrated Terminals 1.10.0 的存储终端搜索框，包括便携存储终端上的同一个搜索框。合成任务列表不在本次范围内。
- 普通名称搜索指不以 `@`、`#` 或 `$` 开头的词。终端用这些前缀区分模组、提示文本和标签，这些写法保持原样。
- 空格表示每个词都要命中，竖线表示命中任意一段。这是该搜索框已有的写法，本次只让其中的普通名称词额外接受另一种语言和拼音。
- 流体页适用同一名称规则。能量页没有对应的双语名称，保持终端原来的查找。
- 打开存储终端并看见物品，需要该模组声明的 Cyclops Core、Integrated Dynamics 和 Common Capabilities。若箱子里的物品必须经过通道才能出现在终端里，开发会话再装上 Integrated Tunnels。这些都不写入本模组的发布要求。
- 1.10.0 声明的 NeoForge 下限不高于 21.1.251。开发用的 NeoForge 仍是 21.1.251，本模组不为此改自己的构建版本。
- 中文来自该模组自带的语言文件或开发会话里已有的外部资源包，不抄进本仓库，也不随本模组发布。
- 测试用的终端和物品由玩家在客户端运行后用创造模式或管理员命令取得，不要求先完成模组任务。
- 已有的两种语言、拼音只用于搜索、语言快捷键不重载资源，以及遇到 Polyglot Tooltip 或 Language Reload 时停用自己，都继续有效。
- 本模组许可证保持 All Rights Reserved。集成终端是独立的开发会话模组，不打进发布包。
