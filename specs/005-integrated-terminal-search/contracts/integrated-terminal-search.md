# Contract: 集成终端存储搜索

集成终端 1.10.0 已安装、语言表就绪、本模组未被同类语言模组停用，且玩家打开的是存储终端或使用同一搜索框的便携存储终端时：

1. 物品页上，一件物品的简体中文名、英文名、无声调连续全拼或首字母被包含在查询的一段普通词里时，该物品命中。大小写不改变结果。当前主语言不改变这四种词。
2. 当前悬停名原来就能命中的查询，仍然命中。铁砧改过的名字只依赖这条原条件。
3. 列表上的名称是当前主语言。拼音不出现在名称、提示框或搜索框里。
4. 物品没有中文名时，拼音和中文名不是本模组的命中条件。英文名和当前悬停名仍可命中。
5. 空格仍表示每一段都要命中。竖线仍表示任意一段命中。每一段普通名称都可以用上面四种词命中。
6. 以 `@`、`#` 或 `$` 开头的词保持终端原来的查找，不因中文、英文或拼音多出条目。
7. 搜索框为空时，终端仍列出本来会列出的物品。
8. 终端会因正则语法拒绝的输入不导致崩溃。结果可以是空的，也可以只留下名称里原样包含这段文字的物品，不得因此列出全部物品。
9. 流体页在该流体两种语言名称都存在时，普通名称适用第 1 条。名称不存在时，只按当前悬停名查找。能量页保持终端原来的查找。
10. 切换主语言不重建搜索词，不打开资源重载画面。切换前已经输入的普通名称词仍然有效。

合成任务列表不使用本契约。

集成终端未安装，或 Polyglot Tooltip、Language Reload 之一已安装时，本契约不生效。客户端仍能进入世界。后一种情况下，已有的停用说明仍然出现，语言选项不被改写。
