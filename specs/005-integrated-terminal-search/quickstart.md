# Quickstart: 集成终端的中英与拼音搜索

实现之后在客户端里核对。创造模式或管理员命令只用于取得物品和放置方块，不代替下面的观看步骤。单测只覆盖「一段查询被某条搜索词包含」，不能代替终端。

对照 [contracts/integrated-terminal-search.md](contracts/integrated-terminal-search.md)。

## 准备

1. `./gradlew runClient`。首次启动需要网络。已有任务会把简体中文资源包下载到 `run/resourcepacks`。不要把资源包或这五份开发 jar 提交进仓库。
2. 进入一个创造模式世界。打开高级提示（F3+H）。若集成终端的物品没有中文，停在这一步，先确认开发会话里的外部资源包已经启用。不要把译文抄进本仓库。
3. 从创造物品栏取出逻辑线缆、物品接口和存储终端零件，连成一个能看见箱子物品的网络。存储终端的注册名是 `integratedterminals:part_terminal_storage`。便携存储终端是 `integratedterminals:terminal_storage_portable`。线缆和物品接口的注册名以游戏里显示的为准。
4. 若箱子已接上物品接口而终端仍是空的，再放上 Integrated Tunnels 的物品通道，直到终端里能看见该物品。不完成模组任务，也不需要合成任务终端。

## 物品页

1. 存入一件中英名称都有的物品。苹果可以用来对照。
2. 主语言为英文时，用它的中文名搜索。主语言为中文时，用英文名搜索。两种主语言下都再用全拼和首字母各搜一次。这些搜索都应看到该物品。
3. 列表上的名字是当前主语言。名称、提示框和搜索框里没有拼音。
4. 用空格写两个都该命中的普通词，只留下两个词都命中的物品。用竖线写两个不同物品的名称，两边的物品都留下。
5. 用 `@` 加一个模组标识搜索。结果与不使用中文、英文或拼音时一致，不因另一种语言多出物品。清空搜索框后，终端里原来的物品都回到列表。
6. 输入一个终端无法当作正则的片段，例如单独的 `[`。游戏不崩溃，列表也不是全部物品。
7. 按住 F3 再按 J。不出现资源重载画面。日志里不要再次出现物品搜索词已构建的那一行。用切换前的另一种语言名称再搜一次，物品仍在。打开的终端若还显示旧语言，关闭再打开后必须是新语言。

## 流体页和能量页

1. 给网络接上一种两种语言都有名称的流体，打开流体页。用另一种语言的名称、全拼和首字母各搜一次，该流体都应留下。没有中文名的流体只按当前名称查找，游戏不崩溃。
2. 打开能量页，输入刚才的拼音。能量页的结果与没装本功能时相同。

## 便携终端

把同一网络上的便携存储终端拿在手里打开。用第「物品页」里已经通过的一种另一语言名称再搜一次，物品仍在。

## 缺件和冲突

1. 从开发运行类路径拿掉集成终端及其配套后再进世界。背包提示、JEI 搜索和语言快捷键仍可用，游戏不因缺少集成终端而崩溃。
2. 只放上 Polyglot Tooltip 或 Language Reload 之一，并保留集成终端。日志里有本模组已停用的说明，进入世界后聊天有一条说明。存储终端里的中文、英文或拼音不再比终端原来的名称匹配多出物品。语言快捷键不改语言选项。
