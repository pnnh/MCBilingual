# Feature Specification: 定格界面并查看另一种语言的整句

**Feature Branch**: `006-frozen-ui-lookup`

**Created**: 2026-10-23

**Status**: Draft

**Input**: User description: "在主语言为英文时，用快捷键把当前游戏画面定格。定格期间只能移动鼠标和再次按键退出。鼠标滑过界面上的英文整句时，在光标旁显示已有的整句简体中文；没有中文则不提示。区分游戏或模组自带的译文和玩家产生的文字，而不是按聊天、书或提示框这些形式一刀切。不处理世界里的告示牌和头顶名字。不做机器翻译。"

## Clarifications

### Session 2026-10-23

- Q: 提示是否固定显示简体中文，并假定主语言始终是英文？ → A: 不固定。英文和简体中文只是一对示例。提示用当前游戏主语言之外的那一种；主语言是英文时显示简体中文，主语言是简体中文时显示英文。
- Q: 画面上只剩翻译并拼接好的文字时，能否用这段文字反查键值再取另一种语言？ → A: 不能。这样会认错，模板填进名字或数字之后的成品更无法对回原句。对不上仍保留的译文时不提示。
- Q: 是否必须停住按下快捷键那一帧，改到后一帧或延迟数帧会不会让查找更准确？ → A: 不必限定为那一帧。按下后数帧内、要看的文字还在时的画面也可以。多等几帧不会把成品文字还原成译文，因此不会更准确。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 定格后从提示框上读出整句对照语言 (Priority: P1)

玩家把主语言留在英文或简体中文中的一种，鼠标停在一件物品上，提示框已经出现。按下定格快捷键后，这幅画面停住，提示框不再因为鼠标移开而消失。玩家把鼠标移到提示框里的物品名上，光标旁出现这件物品在另一种语言里的整句。移到没有另一种语言的文字上时，不出现提示。再按一次快捷键，画面恢复活动，提示消失。

**Why this priority**: 活动中的提示框会在鼠标离开后立刻消失，玩家来不及把鼠标移到提示文字上。定格就是为了让这种文字仍能被查看。

**Independent Test**: 主语言为英文，悬停一件中英名称都存在且不相同的原版物品，在提示框还在时按下定格键。鼠标移到英文名称上能看到整句简体中文。移出该句后提示消失。再按一次后可以继续正常操作物品栏。把主语言换成简体中文后重复一次，鼠标移到中文名称上能看到整句英文。

**Acceptance Scenarios**:

1. **Given** 物品提示框正显示在画面上，**When** 玩家按下定格快捷键，**Then** 当前画面或按下后数帧内仍含这段文字的画面停住，提示框仍留在原地，鼠标可以移到提示文字上。
2. **Given** 主语言是英文且画面已经定格，**When** 鼠标移到该提示框中的英文物品名上，**Then** 光标旁显示这件物品的整句简体中文，而不是其中的单个英文单词。
3. **Given** 主语言是简体中文且画面已经定格，**When** 鼠标移到该提示框中的中文物品名上，**Then** 光标旁显示这件物品的整句英文。
4. **Given** 对照提示正显示，**When** 鼠标移开这一句，**Then** 对照提示消失。
5. **Given** 画面已经定格，**When** 玩家再次按下同一个快捷键，**Then** 定格和对照提示都结束，游戏回到按下之前的界面，没有资源重载画面。

---

### User Story 2 - 定格期间游戏不跟着鼠标走 (Priority: P2)

定格之后，玩家移动鼠标只为了查看文字。点击、拖拽和滚轮不改变背包、按钮或鼠标下的物品，也不把定格画面换掉。除了退出定格的快捷键，其他按键也不操作游戏。

**Why this priority**: 如果定格后点击仍会换物品或关闭界面，停住的画面和鼠标下的文字就会对不上。

**Independent Test**: 在打开的背包上定格。点击格子、滚动滚轮、按下移动键和语言切换键。背包内容和定格画面都不变。只有再次按下定格键才会恢复操作。

**Acceptance Scenarios**:

1. **Given** 背包界面已经定格，**When** 玩家点击、拖拽或滚动滚轮，**Then** 物品不被拿起或移动，界面不关闭，定格画面不变。
2. **Given** 画面已经定格，**When** 玩家按下移动键或中英语言切换键，**Then** 角色不移动，主语言不改变，定格继续。
3. **Given** 玩家结束定格，**When** 立刻点击刚才的背包格子，**Then** 游戏重新接受这次点击。

---

### User Story 3 - 只提示游戏自带的整句，不提示玩家写的字 (Priority: P3)

聊天栏、书、笔记和提示框里都可能混着两种文字。模组发出的系统句子、任务书和游戏物品说明如果另有一种语言，定格后能看到那一整句。玩家自己打的聊天、自己改的名字、自己写的书页和自己加在提示框里的文字没有对照译文可取，悬停时不出现提示，也不出现翻译键。

**Why this priority**: 形式相同的文字来源不同。按聊天或书本整体排除，会漏掉模组已经翻译好的句子；按形式全部纳入，又会把玩家写的字当成应该有译文。

**Independent Test**: 同一次定格中依次指向四段文字：原版按钮、模组发到聊天栏的系统句、玩家刚打出的聊天、玩家重命名后的物品。前两段有对照语言时显示整句；后两段不显示任何提示。

**Acceptance Scenarios**:

1. **Given** 画面上有一个按钮，且这个按钮有另一种语言的整句，**When** 定格后鼠标移到按钮上，**Then** 光标旁显示该按钮的整句对照语言。
2. **Given** 聊天栏里有一条模组发出的系统句，且这条句子有另一种语言，**When** 定格后鼠标移到这句上，**Then** 显示这句完整的对照语言，而不是鼠标下的单个单词。
3. **Given** 聊天栏里是玩家自己打的文字，**When** 定格后鼠标移到这句上，**Then** 不显示提示。
4. **Given** 物品被玩家重命名，或提示框里有玩家写下的说明，**When** 定格后鼠标移到这些文字上，**Then** 不显示提示。
5. **Given** 一段游戏或模组的文字没有另一种语言，**When** 定格后鼠标移到它上面，**Then** 不显示提示，也不显示翻译键。

---

### Edge Cases

- 定格保留按下快捷键时已经画在界面上的内容，或者按下后数帧内这段文字尚未消失时的内容。多等这几帧不会让查找更准确。世界中的告示牌、头顶名字和漂浮文字不参与，即使它们来自游戏文案。
- 画面上只剩已经拼好的成品文字、无法再对应到一条译文时，不提示。不得用这段成品文字反查翻译键。模板填进玩家名、物品名或数字之后的成品也按此处理。
- 一句文字被界面拆成多行时，鼠标放在其中任意可见部分上，提示的仍是对照语言的整句。
- 上下重叠的文字取视觉上最上面的一句。
- 光标旁的对照提示本身不再被取词。提示应避开鼠标正下方的原文，并完整落在画面内；句子很长时可以换行，但不能只剩半句。
- 画面上的文字已经是这句对照语言时，不再重复弹出同一句。
- 数字、耐久和没有对应对照语言的碎片不产生提示。
- 聊天输入框正在输入时，定格快捷键不触发。
- 默认快捷键是按住调试键再按 K，避免和现有的中英切换键冲突。玩家可以在控制设置中更改。改键后旧组合不再定格。
- 同时安装 Polyglot Tooltip 或 Language Reload 时，本模组整体不工作，定格也不出现。
- 缺少对照语言的语言包时，定格仍能开关。所有位置都不弹出提示，游戏不崩溃。
- 当前主语言既不是简体中文也不是英文时，不弹出提示。
- 定格不切换主语言，不重载资源，不把玩家送回标题画面。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 玩家 MUST 能用一个快捷键把当前客户端画面定格，并用同一个快捷键结束定格。
- **FR-002**: 默认定格快捷键 MUST 是按住调试键再按 K。玩家 MUST 能在控制设置中更改。它 MUST NOT 占用中英主语言切换键。
- **FR-003**: 定格 MUST 停住一段仍包含玩家要查看的文字的界面。这段界面可以是按下时已经显示的画面，也可以是按下后数帧内、这段文字尚未消失时的画面。鼠标随后离开原位置时，这些文字仍留在定格画面上。等待这数帧 MUST NOT 被用来提高成品文字的查找准确度。
- **FR-004**: 定格期间，除鼠标移动和定格快捷键外的鼠标操作 MUST NOT 传到游戏。点击、拖拽和滚轮 MUST NOT 改变界面或定格画面。
- **FR-005**: 定格期间，除定格快捷键外的按键 MUST NOT 传到游戏。角色 MUST NOT 因此移动，主语言 MUST NOT 因此切换。
- **FR-006**: 定格期间，鼠标移到仍能对应到一条游戏或模组译文的整句上时，MUST 在光标旁显示另一种语言的整句。主语言是英文时，另一种语言是简体中文。主语言是简体中文时，另一种语言是英文。当前主语言不是这两种时，MUST NOT 显示提示。
- **FR-007**: 提示 MUST 使用游戏或模组已经提供的另一种语言的整句，MUST NOT 临时翻译，MUST NOT 只显示鼠标下单个词所对应的字，MUST NOT 用画面上已经拼好的成品文字反查翻译键。
- **FR-008**: 没有另一种语言、对照句与画面上的全文相同、成品文字已经对不上译文，或这段文字是玩家产生的内容时，MUST NOT 显示提示，也 MUST NOT 显示翻译键。
- **FR-009**: 玩家产生的内容包括玩家打出的聊天、玩家重命名、玩家书写的书页和笔记，以及玩家写进提示框的文字。这些内容无论出现在聊天栏、书本还是提示框中，都不提示。
- **FR-010**: 游戏或模组自带译文的按钮、菜单、物品名称、物品说明、任务与书籍页面，以及模组或游戏发到聊天栏的系统句子，在另一种语言存在且仍能对上这条译文时 MUST 能显示整句对照语言。
- **FR-011**: 世界中的告示牌、头顶名字和漂浮文字 MUST NOT 被取词，即使它们属于游戏文案。
- **FR-012**: 一句被拆成多行显示时，悬停任一可见部分 MUST 仍显示对照语言的整句。重叠文字 MUST 取视觉上最上面的一句。
- **FR-013**: 对照提示 MUST 完整可读，MUST NOT 盖住正在查看的那句原文，也 MUST NOT 再被当成取词目标。
- **FR-014**: 结束定格后，游戏 MUST 回到定格前的位置和界面，并重新接受操作。MUST NOT 出现资源重载画面。
- **FR-015**: 聊天输入框正在输入时，定格快捷键 MUST NOT 触发。
- **FR-016**: Polyglot Tooltip 或 Language Reload 已安装时，定格功能 MUST NOT 生效。缺少对照语言时，定格开关仍 MUST 可用，且不崩溃。

### Key Entities

- **定格画面**: 按下快捷键时，或按下后数帧内要查看的文字还在时，玩家看见的那一幅界面，以及其中每一句可查看的文字。鼠标移动不改变它，结束定格后丢弃。
- **游戏句子**: 游戏或模组提供的一整句，并且仍能对应到它自己的译文。查看时用另一种语言的整句，不用单词，也不用成品文字反查。
- **玩家文字**: 玩家打出、改名或写进书、笔记、提示框的文字。没有配套译文，查看时不提示。
- **对照提示**: 贴在光标旁的另一种语言整句。只在定格期间、鼠标正对着一句仍能对上译文的游戏句子时出现。主语言是英文时它是简体中文，主语言是简体中文时它是英文。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家能在物品提示框还显示时定格，并把鼠标移到物品名上。主语言为英文时光标旁出现整句简体中文；主语言为简体中文时光标旁出现整句英文。
- **SC-002**: 定格后的点击、滚轮和其他按键不改变背包或主语言。再次按下定格键后，一秒内可以继续操作原来的界面。
- **SC-003**: 同一次定格里，带对照语言的按钮和模组系统聊天能看到整句对照语言；玩家聊天、重命名和玩家书写的书页看不到提示。
- **SC-004**: 没有对照语言的游戏句子、以及只剩成品文字而对不上译文的句子，都不产生提示，画面上也不出现翻译键。
- **SC-005**: 世界中的告示牌和头顶名字在定格后不被取词。
- **SC-006**: 打开和关闭定格都不出现资源重载画面，也不把玩家送回标题画面。两种主语言下各做一次，结果相同。

## Assumptions

- 简体中文和英文可以互换。当前游戏主语言是哪一种，提示就是另一种。主语言已经是某句的对照语言、画面上的全文已经等于这句对照语言时，不再重复弹出。
- 查找准确度来自这句话是否仍对应到一条译文，不来自多等几帧，也不来自拿画面上的成品文字去猜键值。
- 定格快捷键默认用调试键加 K，因为调试键加 J 已经用于中英主语言切换。
- 玩家只明确要求忽略定格期间的其他鼠标事件。角色移动和语言切换若仍然生效，定格画面会和游戏状态分开，因此这些按键在定格期间也不传给游戏。
- 现有的物品提示第二行、搜索和中英切换保持不变。本功能只在定格期间额外给出整句对照语言。
- 译文仍来自游戏、资源包或其他模组已经提供的文案。本模组不携带译文。
- 只支持简体中文和英文。
