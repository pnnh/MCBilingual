# Quickstart: 定格界面并查看另一种语言的整句

在项目根目录执行。客户端用 `./gradlew runClient`。句子判断的单测是 `./gradlew test --tests pnnh.mcbilingual.freeze.*`。没有亲自定格并移动鼠标之前，不要把下面的界面步骤记成已经通过。两种主语言都要做。玩家可见行为见 [frozen-ui-lookup.md](contracts/frozen-ui-lookup.md)。

## 准备

- Minecraft 1.21.1，NeoForge 21.1.251。
- 简体中文和英文语言表都已经加载。原版物品在主语言为英文时，普通提示框能看到中文第二行。
- 不安装 Polyglot Tooltip 和 Language Reload。
- 创造模式即可，不需要任务线。

## 主语言为英文

1. 语言设置留在英文。进入世界，打开背包，鼠标停在苹果上，直到英文提示框出现。
2. 按住调试键再按 K。
3. 把鼠标从物品上移到提示框里的 “Apple”。
4. 期望：画面停住，提示框还在。光标旁出现整句「苹果」，不出现翻译键。
5. 鼠标移出这句英文。期望对照提示消失，定格画面不变。
6. 在格子上点击、滚动滚轮。期望物品不被拿起，界面不关闭。
7. 再按一次调试键加 K。期望定格结束，没有资源重载画面，随后可以正常拿起物品。

## 主语言为简体中文

1. 用现有的调试键加 J 把主语言换成简体中文，或在语言设置里选简体中文。确认普通提示框的物品名是中文。
2. 再次停在苹果上并定格。把鼠标移到「苹果」上。
3. 期望：光标旁出现整句 “Apple”。不出现翻译键，也不把主语言改回英文。
4. 结束定格。期望没有资源重载画面。

## 系统句、玩家文字和成品文字

1. 主语言留在英文。再次定格，鼠标移到一个英文按钮上。期望出现该按钮的整句中文。
2. 让一个会发翻译句子的模组往聊天栏写一句英文，或使用一条原版的可翻译系统句。定格后移到这句上。期望是整句中文，不是单个单词。
3. 自己在聊天栏打出 “Apple” 并发送，再定格并把鼠标移上去。期望没有提示。这句成品英文不能反查成「苹果」。
4. 用铁砧把一件物品改成英文名字，定格后移到这个名字上。期望没有提示。
5. 看世界里的告示牌或生物头顶名字。定格后移到那些字上。期望没有提示。

## 其它输入

1. 按住前进键再定格。期望角色不再继续移动。结束定格后前进恢复。
2. 定格期间按调试键加 J。期望主语言不变。
3. 打开聊天输入框后再按调试键加 K。期望不进入定格。
4. 在控制设置里把定格键改成别的按键。期望调试键加 K 不再定格，新按键可以定格。

单测覆盖对照语言方向、带字面量参数的模板、缺失译文、当前主语言不在两种之内、纯字面量，以及成品字符串不能反查。界面步骤只在客户端里核对。
