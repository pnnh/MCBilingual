# Contract: 定格界面并查看另一种语言的整句

玩家可见行为。实现不另造译文，也不把翻译键显示出来。字段含义见 [data-model.md](../data-model.md)。

## 开关

- 默认组合是按住调试键再按 K。玩家在控制设置里绑定其它键后，只认新绑定，调试键加 K 不再定格。
- 聊天输入框正在输入时，组合和已绑定的键都不进入定格。
- 第一次按下进入定格，再按一次结束。结束后面面回到原来的界面，没有资源重载。
- 安装了 Polyglot Tooltip 或 Language Reload 时，没有这个快捷键的效果。

## 定格画面

- 停住的是按下时玩家已经看见的那一帧，包括当时的物品提示框。
- 定格期间移动鼠标不改变这幅图。
- 点击、拖拽、滚轮、角色移动、转身和中英语言切换都不作用于游戏。
- 结束后，下一次点击和移动重新作用于游戏。进入前若能转动视角，结束后在没有界面时恢复转动。

## 取句

给定鼠标下最上面的一块文字。对照语言由当前主语言决定：主语言是英文时为简体中文，主语言是简体中文时为英文。

| 来源 | 提示 |
| --- | --- |
| 游戏或模组的翻译组件，对照语言存在，并与画面上的全文不同 | 光标旁的整句对照语言 |
| 同一组件被拆成多行 | 仍是拆开前的整句对照语言 |
| 没有对照语言 | 不提示 |
| 画面上的全文已经是这句对照语言 | 不提示 |
| 只剩拼好的成品文字，已经对不上译文 | 不提示 |
| 模板填进名字或数字之后的成品，且没有原翻译组件 | 不提示 |
| 玩家聊天、玩家改名、玩家写的书页、笔记或提示说明 | 不提示 |
| 世界中的告示牌、头顶名字、漂浮文字 | 不在定格的文字里 |
| 当前主语言既不是简体中文也不是英文 | 不提示 |

## 语言

- 只使用已经加载的 `zh_cn` 和 `en_us`。
- 本模组不携带这两份译文，也不显示裸翻译键。
- 缺少对照语言时，定格仍能开关，游戏不崩溃。
