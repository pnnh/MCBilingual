# Data Model: 定格界面并查看另一种语言的整句

## FreezeSession

一次定格的全部状态。同时最多存在一个。

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| active | 是否正在定格 | 按下快捷键时从关闭变为打开。再次按下、离开世界或冲突模组使本模组停用时变为关闭 |
| image | 定格时的整窗画面 | 只在打开时存在。关闭时释放。不写入磁盘。来自按下时玩家已经看见的那一帧 |
| hits | 打开那一帧的文字矩形，从底到顶 | 打开后不再增删。鼠标移动不改变它 |
| cursorReleased | 进入时是否放开了被抓住的鼠标 | 结束时仅当进入前鼠标被抓住、且当前没有界面时再抓回去 |

状态：

1. 关闭。正常绘制，每帧替换一份尚未定格的矩形草稿，帧末只留最新一份。
2. 打开。不再采集矩形，不再画实时世界。鼠标移动只更新提示。
3. 回到关闭。画面和矩形丢弃，游戏重新接受输入。

## UiSentence

一句可以提示的游戏或模组译文。

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| source | 拆行之前的原组件 | 组件树里必须有翻译内容。纯字面量和没有组件的成品字符串不是句子 |
| counterpart | 对照语言下的整句 | 主语言是 `en_us` 时来自 `zh_cn`，主语言是 `zh_cn` 时来自 `en_us`。模板参数里的字面量保留原文。翻译键没有对照译文、当前主语言不是这两种、或结果等于翻译键时，整个句子不存在 |
| visible | 当前主语言下这句的全文 | 与 `counterpart` 相同时，这句不产生提示 |

一行视觉文字可以指向同一个 `UiSentence`。提示用 `counterpart`，不用这一行自己的碎片，也不用碎片去反查键值。

## TextHit

定格画面上的一块可指向区域。

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| bounds | 界面坐标里的可见矩形 | 经过绘制矩阵，并与当时的裁剪相交。空矩形不保留 |
| sentence | 这一块所属的整句 | 没有句子的绘制不产生 `TextHit` |
| order | 绘制先后 | 越大越靠上。鼠标同时落在多块上时取得分最高的一块 |

多个 `TextHit` 可以共享同一个 `UiSentence`。玩家文字、世界投影文字和已经拼好的成品字符串都不产生 `TextHit`。
