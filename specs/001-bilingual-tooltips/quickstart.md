# Quickstart: 物品与 Jade 双语名称

## 准备

- 使用本仓库的 Java 21 与 Gradle。
- 日常检查：`./gradlew runClient`。
- 中文语言包和 Jade 放到这次运行的 `run/mods`。不要把它们写进发布依赖。
- 语言包可用 I18nUpdateMod3 与 Minecraft-Mod-Language-Package。没有 Maven 坐标时用 jar，不把它们的源码抄进仓库。

## 自动检查

实现 `SecondaryNamePolicy` 后运行：

```text
./gradlew test
```

覆盖：中文主语言加英文行、英文主语言加中文行、文本相同不加行、结果等于翻译键不加行、第三种主语言在两者都不同时给出中文再英文两行。

## 客户端检查

1. 游戏语言设为简体中文，进入世界，悬停中英名称不同的原版物品。标题是中文，下一行是灰色英文。打开语言设置，语言仍是简体中文。
2. 把语言改成英文并让原版完成一次语言加载。悬停同一物品。标题是英文，下一行是中文。
3. 找一个两种可见名称相同的物品，确认没有额外行。
4. 给物品起铁砧名。标题是铁砧名。语言包原名不同时才出现额外行。
5. 装上 Jade，瞄准方块和实体。名称下有另一语言。卸掉 Jade 再启动，物品提示框仍可用，能进入世界。
6. 移走中文语言包再启动。能进入世界。提示框不出现 `block.minecraft...` 或 `item.minecraft...` 形式的第二行。
