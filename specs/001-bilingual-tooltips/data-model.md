# Data Model: 物品与 Jade 双语名称

## LanguageTexts

启动和每次客户端资源重载后重建。

| 字段 | 规则 |
| --- | --- |
| chinese | `zh_cn` 的只读语言表。资源重载完成前为空。 |
| english | `en_us` 的只读语言表。 |
| currentLanguage | 读取游戏当前选择的语言代码，不在这里缓存。 |

关系：一份存储服务所有物品、Jade 目标和后续搜索。切换主语言不重建表，除非发生真正的资源重载。

## SecondaryNameRequest

一次显示查询的输入。

| 字段 | 规则 |
| --- | --- |
| title | 界面已经决定的标题原文。 |
| translationKey | 语言包里的名称键。没有键时无法提供第二行。 |
| currentLanguage | 查询瞬间的游戏语言。 |

## SecondaryNameLine

策略的输出。零行、一行或两行。

| 字段 | 规则 |
| --- | --- |
| language | `zh_cn` 或 `en_us`。 |
| text | 已修剪的可见文本。禁止等于翻译键。 |
| order | 当前语言在语言对内时只有另一语言，顺序为 0。当前语言在语言对外时，中文为 0，英文为 1，与标题重复的不产出。 |

校验：

- 文本与标题在忽略大小写和首尾空白后相同，则丢弃。
- 文本为空或等于翻译键，则丢弃。
- 同一查询内同一语言最多一行。

## 状态

语言表只有两种状态：未就绪（资源还没加载完，调用方不加行）和就绪。没有单独的「双语关闭」状态。本阶段第二行始终按上述规则计算。
