# Feature Specification: 物品与 Jade 双语名称

**Feature Branch**: `001-bilingual-tooltips`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "类似 PolyglotTooltip，不改变主语言，为物品提示框增加第二语言。前期支持 Jade 的瞄准提示。只处理简体中文和英文。翻译文案来自已安装的语言包，不由本模组提供。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 物品名称下多一行另一种语言 (Priority: P1)

玩家把游戏语言设成中文或英文后，鼠标悬停在物品上。提示框标题仍是当前游戏语言的名称。若另一种语言的名称不同，标题正下方多一行该名称。游戏设置里的语言不变。

**Why this priority**: 这是本阶段双语显示的主路径。没有这一行，玩家仍然要切语言才能读另一种名称。

**Independent Test**: 只装本模组和中英语言包，进入创造模式，悬停一个中英名称不同的原版物品。标题是当前语言，下一行是另一种语言，语言设置未被改写。

**Acceptance Scenarios**:

1. **Given** 游戏语言是简体中文，且该物品有不同的英文名，**When** 玩家打开物品提示框，**Then** 第一行是中文名，紧接着一行是英文名，语言设置仍是简体中文。
2. **Given** 游戏语言是英文，且该物品有不同的中文名，**When** 玩家打开物品提示框，**Then** 第一行是英文名，紧接着一行是中文名，语言设置仍是英文。
3. **Given** 两种语言的可见名称相同，**When** 玩家打开提示框，**Then** 不增加额外名称行。
4. **Given** 提示框里还有附魔、说明等其他行，**When** 第二语言名称出现，**Then** 它紧挨在标题下面，不跑到说明中间或末尾。

---

### User Story 2 - Jade 瞄准名称同样多一行 (Priority: P2)

安装 Jade 后，玩家瞄准方块、流体方块或实体。Jade 原有名称保持当前游戏语言。另一种语言的名称不同时，在该名称下多一行。

**Why this priority**: 用户点名前期要支持 Jade。它与物品提示框是同一条阅读需求，但是另一块界面。

**Independent Test**: 在故事 1 可用的环境里加上 Jade，瞄准一个中英名称不同的方块和一只实体。覆盖层名称下出现另一语言，游戏语言不变。不装 Jade 时，故事 1 仍然成立，游戏能进世界。

**Acceptance Scenarios**:

1. **Given** 已安装 Jade，游戏语言是简体中文，**When** 玩家瞄准一个有不同英文名的方块，**Then** 覆盖层在中文名下显示一行英文名。
2. **Given** 已安装 Jade，**When** 玩家瞄准实体，**Then** 采用与方块相同的第二语言规则。
3. **Given** 未安装 Jade，**When** 玩家进入世界并查看物品提示框，**Then** 故事 1 仍然可用，且不因缺少 Jade 而失败。

---

### User Story 3 - 缺翻译时安静退让 (Priority: P3)

没装中文语言包，或某个模组物品只有一种语言时，提示框保持原样，不出现翻译键原文，也不阻止游戏进入。

**Why this priority**: 翻译数据不在本模组里。缺包是预期状态，不是故障。

**Independent Test**: 不安装 I18nUpdateMod3 和 Minecraft-Mod-Language-Package，启动游戏并悬停原版物品与一个没有中文名的模组物品。

**Acceptance Scenarios**:

1. **Given** 没有中文语言包，**When** 玩家悬停物品，**Then** 游戏正常进入，提示框不新增一行翻译键。
2. **Given** 某个名称只有一种语言文本，**When** 玩家查看提示框或 Jade，**Then** 不为缺失的那种语言增加一行。

---

### Edge Cases

- 游戏语言既不是简体中文也不是英文时，标题保持游戏当前名称；中文和英文里与标题不同的名称各增加一行。不把游戏语言改成中文或英文。
- 第二语言文本与标题只有大小写或首尾空白差异时，视为相同，不增加一行。
- 同一提示框被多次刷新时，第二语言行不重复堆叠。
- 物品没有自定义名时用语言包名称。物品有铁砧自定义名时，标题保持自定义名，不为自定义名编造翻译；语言包里的原名若与自定义名不同，仍可作为第二语言行。
- 拼音、搜索词不出现在提示框或 Jade 里。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 模组 MUST 在不改变玩家当前游戏语言的前提下，为物品提示框提供另一种语言的名称。
- **FR-002**: 支持的语言对 MUST 只有简体中文和英文。
- **FR-003**: 当前游戏语言是这两种之一时，额外行 MUST 是另一种语言，且只有一行。
- **FR-004**: 额外行的可见文本与标题相同时，模组 MUST 不添加该行。
- **FR-005**: 某种语言没有该条目的译文时，模组 MUST 省略该行，MUST NOT 把翻译键显示成第二行。
- **FR-006**: 额外行 MUST 紧接在标题之下，并在视觉上弱于标题。
- **FR-007**: 安装 Jade 时，方块、流体方块和实体的瞄准名称 MUST 使用与物品提示框相同的第二语言规则。
- **FR-008**: 未安装 Jade 时，物品提示框功能 MUST 仍然可用，游戏 MUST 能进入世界。
- **FR-009**: 中文文案 MUST 来自已经加载的资源包或其他模组。本模组 MUST NOT 自带中英翻译文件。
- **FR-010**: 缺少中文语言包时，模组 MUST 继续运行。
- **FR-011**: 本功能 MUST NOT 要求安装 PolyglotTooltip 或 Language Reload。
- **FR-012**: 提示框和 Jade MUST NOT 显示拼音。

### Key Entities

- **语言对**: 简体中文与英文。当前游戏语言决定哪一种出现在标题，另一种作为额外行。
- **名称行**: 玩家在提示框或 Jade 里读到的一行可见名称。包含所属语言，以及它是标题还是额外行。
- **译文条目**: 某个名称在一种语言中的文本。可以缺失。缺失不是空字符串冒充，而是没有可用译文。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在中英名称不同的原版物品上，玩家一次悬停就能看见当前语言标题和另一语言的一行名称，且游戏语言设置保持原值。
- **SC-002**: 抽查 20 个中英名称相同或缺少其中一种译文的物品，额外名称行数量为 0。
- **SC-003**: 安装 Jade 后，瞄准方块和实体时，第二语言名称与物品提示框规则一致。卸下 Jade 后，物品提示框仍可用，客户端能进入世界。
- **SC-004**: 不安装中文翻译模组时，客户端仍能进入世界，提示框不出现翻译键形式的第二行。
- **SC-005**: 上述检查可在一次客户端会话内完成，不需要专用服务器。

## Assumptions

- 本阶段的第二语言行只覆盖物品提示框标题，以及 Jade 的方块、流体方块和实体名称。附魔名、流体独立提示、菜单、聊天、地图和书本不在本规格内。
- 布局固定为标题下另起一行。不做单行拼接、字号缩放、高分辨率收缩，也不提供三种显示模式。
- 额外行使用更淡的颜色与标题区分。具体色值由实现选定，玩家本阶段不能配置。
- 「主语言切换」由 `003-language-hotkey` 负责。本规格只保证：无论当前主语言是哪一种，额外行都是语言对里的另一种，且查看提示框本身不切换主语言。
- 铁砧自定义名保留为标题。第二行只使用语言包中的原名，不翻译自定义名。
- I18nUpdateMod3 与 Minecraft-Mod-Language-Package 是推荐的运行时语言来源，不是本模组的必装项。
